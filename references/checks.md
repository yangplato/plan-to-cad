# 出图检查与记录

每个户型在已有项目记录中追加结果。最短的一条记录要说明位置、依据、判断、量测结果和状态。例如标明“原图已标”“原图可见”“按使用推断”“用户已决定”“已从交付 CAD 实测”。对推断项写清使用的几何关系。保留关键局部原图与可复算的坐标或数值。没有对照文件时，照常完成下列检查。

| 检查对象 | 实际怎么查 | 留下什么证据 |
|---|---|---|
| 尺寸与配准 | 复算每条可读尺寸链。区分墙面、墙心、控制线。量最终 CAD 尺寸界线两端。对照标注显示值和几何实量。叠原图时用分散的刻线或墙角定位，再用独立控制点核验。 | 各段数字、起止对象、单位、残差。看不清的边记原图像素范围，必要时换算成毫米范围。 |
| 墙和房间 | 检查材料轮廓闭合、墙交点同坐标、墙面沿线对齐，排除碎缝、重墙、重叠填充。用临时封洞检查独立房间，再还原真实洞口检查走道能否到达。开放客餐区保留连通。遮挡处区分墙、外饰边和阴影。 | 闭合或漏口位置、房间与出入口关系、深浅分界和推定墙厚。 |
| 门窗与墙 | 检查每个门窗的宿主墙、洞口宽和墙厚。洞内清除墙材和填充。框端与洞口端面衔接。采用四线直窗时保持平行，两端收在窗框。弧窗各线同心或等距过渡。核对铰点、开向及门套回边。 | 放大洞口局部，记录墙洞宽和框内宽。 |
| 门前、洞内、门后 | 沿正常路线靠近、通过、转向。量各截面共同可用的净宽。相邻门垛、门框、突出柜体都计入。检查门扇全程扫掠，再计入全开门扇厚度。 | 标出最窄位置、相邻门开向、墙洞宽、框内宽和实际模型通行投影。 |
| 家具接触与留空 | 给柜背、床头、电视柜等选真实可见的接触边。直边贴墙要量零缝和有效共边长度。弧背按形状验相切。检查拼柜两端、窗台和门套。自由摆放的物件按拉椅、行走、开柜或设备安装需要留空。 | 每处写“贴合、拼接或留空”，记录对应边和实量。型号暂缺时把设备预留列为推断。 |
| 家具画法 | 对应原图逐件清点，查占地、开门侧及朝向。定制物的每条内线须有可说明的构件、分件、开口或所用图例。 | 来源文件和块名，或定制依据。保留可解释的水槽、灶具等线。 |
| 分层和原生文件 | 常用八类为承重墙、构造墙、门、窗、活动家具、固定家具及设备、尺寸、建筑附属。墙轮廓与填充归同一类别，给两类墙不同显示色。家具块参照放在所属家具层，块内及嵌套线条放 0 层，必要时用图元线宽保留层级。后台从最终 DWG 复开，确认单位和尺寸实体。 | 四种实际显示状态：全开、仅关活动家具、仅关固定家具、两层都关。比较隐藏的对象，同时确认墙和门窗仍可见。核对全开时两类墙是否可辨。 |

**辅助检查。** 若可得到交付 DWG 读回的 DXF，可用已安装 `ezdxf` 的 Python 运行以下只读检查。替换示例文件名。自定义图层时加 `--layers "活动层名" "固定层名"`。

```sh
python scripts/check_furniture_layers.py "交付读回.dxf"
```

脚本检查指定家具层上的模型空间块、嵌套图元的归层及两组数量。另用原营销图确认家具件数、真实归类，并在可用的原生 CAD 中实际关层。

## 有同户型人工 DWG 时

先保存图片独立稿、尺寸记录及版本标识。若要证明独立，保留可重新打开或能等效重现的冻结图形。参考 DWG 仅在此后读取。确认同户型、同朝向和对应版本。如果一个文件有多个方案，用房间、门位和固定结构辨别，记下选哪一组。无法对应时结束该项比较，回到图片主线。

- 用相同单位、方向、尺度和共同锚点配准。将两份 CAD 分别叠至同一张未经二次拉伸的营销图。两份图使用相同的变换规则。
- 分开比较墙面位置、墙厚、洞宽、整窗位置和可见玻璃段。记录两份数值、差值、原图可见范围及判断。改变合理的读图边界或配准点后排名会变时，结论写“原图不足以分辨”。
- 从阴影、遮挡、符号简化、刻线所指墙心或墙面的差别、人工图版本差等原因解释偏差。将有证据的原因与可能原因分开。谁更贴营销图，只在该处、该指标下成立。
- 把使用逻辑导致的后续修订另记。保留独立稿的原始差值。需要改已标尺寸、承重墙或房间布局时，按用户确认的边界处理。

## 没有人工 DWG 时的交付措辞

可写“图中已标的某段为 X mm，CAD 实量 X mm”“窗框两端接墙”“柜背与墙共边 Y mm”“未标门洞按墙面和开门路线推定为 Z mm”。对没有独立测量依据的墙位、窗宽等尺寸，记录误差来源或可见范围。此时跨图纸的毫米误差没有可报告的测量值。
