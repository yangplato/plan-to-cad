# 先找房间和可用的进出路径

从营销原图建立房间清单。给每个可辨空间写用途、室内点和实际边界的大致位置。绘图者与独立审图者各自先做这一步。看[虚构图的三种判断](../assets/读门与坐用示例.png)，然后读本案自己的原图。

1. 为每间房画出完整周界。圈定墙心附近的外框或转角。用于放大看的裁切框可能伸到邻房，不宜拿来当墙边。用[逐房扫描](room-entry-survey.md)让原始像素先给每条边上的可能入口，包括初步门表中漏记的位置。在候选卡最左格先看无标记原图。再比较备选圆弧、开启扇、关合线和墙垛。
2. 从住房入口，用室内可通行的空间走到每间卧室、卫生间及工作空间。记下每一步跨过哪段墙。若唯一通路必须穿过露天阳台、另一间私卧或固定玻璃，回到该房全部周边，分别从门内与门外看。套内卫生间、衣帽间或图示确有独立外廊的房间按实际布置解释。找到常见路线只帮助提出假设；在原图还须找到与该假设一致的洞端、扇线或固定边依据。
3. 逐扇标铰点和自由端。双扇不一定同宽。把每扇转回关闭平面，核两扇能否相接。只见一条主要弧时，仍检查另一端有没有较短的独立扇和第二段弧。有多种入口假设时，注明各自能解释的像素和相矛盾的实际线型。
4. 初定墙厚、外形及洞口后，再按原图沿墙芯查每段深浅。图面墙芯角色以本案原图与图例为准。[从原墙芯生成色段](apply-wall-tones.md)可用于颜色证据连续的工作副本。已确认的承重方案如需变更，请用户决定。
5. 逐件放家具，还要核每个使用者在什么位置坐、起身、伸腿、开柜或使用设备。[家具使用边与净距](use-clearance.md)从保存的图上测真实轮廓。床和定制柜靠墙吸附；座位前方按人的动作保留可用空间。原图未标家具尺寸时，根据完整家具、人体尺度和邻物位置自行判断，在本房能调整的范围内选取最小合理改动。

读图和编译在同一图纸的工作副本上进行。首稿对外提交前，作者对每处仍可能改变使用关系的疑点保留入口卡或实际截面。修改已封存的读图结论时，保留最初观察，把最终选择和依据另存。独立盲审按实际首稿判定。
