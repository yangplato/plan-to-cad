# 用原图确认墙芯，再从毫米墙段生成墙材

## 在原图上找分段

在原始图像上操作。以左上为 (0,0)，x 向右，y 向下。所有 *_px 使用原图像素。图面范围和像素段的两端都包含在内。使用本图无遮挡的墙芯来选色。把图例中的材料名、深浅、墙厚分开判断。没有图例时只说“深墙芯”“浅墙芯”。

给每条可辨的水平或垂直墙标一条大致轴线。量取墙芯的像素宽度范围，以垂直轴线的方向给出允许找线的像素距离。大致轴线的端点限定沿墙测读的起止范围。平行候选难区分时，在当前轴的清楚位置补一个 anchor_px。倾斜、弧形或明显移动中心线的墙需另行读图或拆段。

填入以下结构。数字仅展示一张合成小图的输入格式，每案重新取点。

```json
{
  "plan_box_px": [8,13,175,120],
  "samples": [
    {"material":"深墙芯","points_px":[[35,46],[53,46]],"radius_px":1},
    {"material":"浅墙芯","points_px":[[68,46],[156,78]],"radius_px":1}
  ],
  "axes": [
    {"id":"W1","a_px":[17,50],"b_px":[159,50],"core_width_px":[5,8],"search_px":7,"anchor_px":[35,46]}
  ],
  "nonwall_points_px":[[102,46],[61,62]],
  "exclude_boxes_px":[]
}
```

程序从本图的样点估计 RGB 色心和色差范围，并分开相近的两类；样本受污染时，应重取样。芯宽与法向搜索带由执行者量取。算法先在横断面找两侧可见、宽度相符的连续色带，再用多个断面找稳定的直墙轴。局部偏移过大、色样不符、双线难分、交角过厚、过短色段均可产生未判区。邻近其他相似物体时，用原图和锚点选择墙轴。可按图调整 radius_px、tolerance_rgb（RGB 欧氏色差）、min_run_px（默认最小芯宽且至少两像素）或 jitter_px（墙芯容许摆动）。同色家具与墙在像素上可能完全一致。

校对图的材料颜色见输出 colours。橙线表示 unresolved。紫线表示候选覆盖非墙负样点，整段 conflict。粉叉标出负样点。叠图保留原图尺寸，黑白轴编号对应 JSON 的 overlay_no。changes 列出颜色或可读状态每次变化两侧的像素端点。沿墙在原图逐段确认；空白区可能是洞、遮挡或低清，回看门扇、门框、窗轨和两端墙垛。已知家具、阴影或门槛可列入 exclude_boxes_px。非墙点只约束该处的检查。算法没有把建议自动送入 CAD 的路径。

## 从墙段与洞口建图

WCS 毫米坐标 x 向右、y 向上。根据原图标数为 x、y 分别定标并翻转 y。墙 a、b 是同一水平/垂直墙的中心轴端点。width_mm 是两墙面之间的全厚；中心线到每个墙面均为半厚。量得外缘线时，先向墙内偏移半厚。横墙沿 x、纵墙沿 y，允许反向录入。在材料、厚度或中心轴变化处拆段。

端点相同的同一直墙自动平接。正交转角的两条中心轴端点共用精确交点时，各延长相邻墙半厚，闭合外角。T 接处将支墙中心轴终点落在主墙中心线上。直达已知端面的墙可单独给 cap_a_mm 或 cap_b_mm，值 0 表示截到该端点，正数沿轴向外伸。柱、弧墙、不等距偏心变截面需要单独按原图构造。

洞口 a、b 表示两侧门窗净洞口端面与宿主中心线的交点，按墙端点同一坐标系登记。hosts 收录每个覆盖该洞口的直线段。跨材料洞口可列多个共线宿主。先画跨洞连续墙段，由函数统一扣除净洞。检查短墙垛时登记实际长度，留出两端净洞。默认要求 a、b 外侧立即接到实墙。仅当原图可见端部接框或自由端时，按端点顺序设置 jamb_support（wall、frame、free_end）；后两者需另查框或端部图符。填充与边界共用扣洞后的多边形；材料优先序仅处理相交结点。建议用各室明确净空点、非墙家具内部点作 clear_points_mm，防止误填房间。

from build_wall_runs import draw_wall_runs

# layer_gray 按结点优先级列材料层。先设 doc.units=4，再建好对应 CAD 图层。
draw_wall_runs(msp, walls, openings, layer_gray, clear_points_mm=room_points)
for opening in openings:

每条墙形如 `{"id":"W1","a":[0,0],"b":[3000,0],"width_mm":180,"material":"深墙"}`。每个洞如 `{"id":"D1","hosts":["W1"],"a":[500,0],"b":[1300,0],"kind":"swing"}`，绘制门扇时再按图符工具约定补充开向等字段。门洞被另一墙段占据、净洞超出宿主或接墙端没有实材会抛出异常，先回查原图再修正墙段或宿主。
