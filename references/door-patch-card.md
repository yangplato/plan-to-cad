# 从源图像素读门

输入使用转正后的原图像素，向右为 X 正方向，向下为 Y 正方向。框住整处门洞，包含两侧可能的铰点。程序自动向外取图。毫米比例由制图者给出。半径范围按单扇估计，试子母门时涵盖小扇。

```sh
python door_patch_card.py source.png --box 40 37 64 62 --rooms 90 62 20 63 --opening 53 46 53 74 --h-line 50 --v-line 54 --mm-per-px 25 --radii-mm 290 790 --out /tmp/door-read
```

以上数字来自模拟图。两侧房间各取一点，尽量靠近门前、门后。可省略房间点，也可用 `--opening` 给出一至两组候选洞口端点。`--h-line` 填可疑水平墙的 Y，`--v-line` 填可疑竖墙的 X。程序独立搜索框内全部铰点和八种开向。人工标记仅供对照。需要 Python、NumPy、SciPy、Pillow。

打开 **door-patch.png**，先看第一行原图、局部对比增强和人工标记。第二行起按候选显示。P 是铰点，C 是关闭端点，O 是开启端点。**P–C 决定洞口轴，P–O 指向门扇打开一侧。** 橙色和蓝色短线表示预测，绿点表示达到亮度条件的采样点。发现 `same_arc_two_possible_axes` 时，保留两个方向。只见弧、只见直边、遮挡严重时，由制图者回看原图。

**door-patch.json** 给出弧、叶各六段覆盖，27 条射线提取的原图亮线或暗线、独立拟合后的圆心与半径偏移，以及邻近半径、弧两端、叶尖外延伸的对照数据。`context` 列明两点是否分居轴线两侧、朝哪个房间开、给定端点与拟合铰点的像素偏差、预测洞口中段与两端外侧的灰度差。灰度差可以来自墙体、柜体或描边。房间连线与单扇范围不相交，也可能是房间点偏远或遇到子母门。双扇需两条独立弧和开启扇，并核对两条轨迹的关闭端是否相遇。图上的扇半径不能直接充当洞口净宽。

运行 `python door_patch_card.py --self-test /tmp/door-fixtures` 可复做 18 组模拟。八种门向均找到原方向。模拟 27.8／14 像素子母扇的关闭端相距 0.78 像素。两条正交半径均有线时保留双解。只见弧、只见叶、圆形符号、贯穿直线、纯板缝、两灰度级弱线、实心扇形和大幅遮挡都返回待看。另用这套底图做 16 次缩放、色调、噪声和 JPEG 压缩组合，也都找回相应门向。结果仅覆盖模拟图；纯色差而等亮度、非正交、非九十度、低分辨率及不同制图习惯仍需按原件复查。

局部图里的地板线、柜边和相邻构件可抬高错误候选的分数。单一高分与源图事实仍须区分。对疑似转向的洞同时核对房间附近两侧的地面点；不可只按候选排行改宿主。此处为已知门区的回顾试测，未评估自动发现全部洞口的能力。
