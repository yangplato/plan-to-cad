# 绘图预防、叠图判读与成品复量

画图时可以避免同一构造使用两套坐标。叠图用来判断绘图者选的构造、位置和用途是否与原营销图相符。原生读回检查实际写进 DWG 的图元。三步各留对应证据。自动扫描可以发现错台候选；窗间是实垛还是连续框、桌边长条是坐凳还是装饰，由审图者对照原图判断。

| 对象 | 作图时可预防 | 成图后用原图叠加判定 | 从最终 DWG 复量 |
|---|---|---|---|
| 共墙、墙柱和厚度转换 | 相邻墙段调用同一共用面。依据两侧空间选对齐的是内面、外面或墙心。用同一轮廓生成填充。 | 沿墙两侧跨过接头查看，放大主图墙芯与同页其他图示。确认突起有真实柱头或构造依据。区分隔墙向单侧变薄和整段移位。 | 查两侧外皮、墙厚、相邻房间净宽和 HATCH 边界。预期平齐处量错台。实柱凸起记录宽度和法向偏移。 |
| 洞端短垛、连续外窗 | 先定洞端支承，再扣墙和放框；为连续外窗选定内框接墙基准。相邻卧室的封窗共用外框基准。 | 逐个对照窗端是否有短实垛。沿外立面穿过每处隔墙查看透光线是否连续，再看隔墙止于哪一道内框。平行线的数量不能单独说明围护是窗还是栏杆。 | 分别量净洞、两端墙段或框长。在墙材上查洞腹是否贯通。核窗框末端与洞侧的实际共点或共面。 |
| 楼梯平台短柱、门与栏杆 | 让柱、平台侧墙、门垛和转角栏杆引用已选的同侧外皮。栏杆按实际内外线收转角。 | 同时看窗两端柱头和梯段两侧墙面。原图的柱头可能向平台内偏心；只按块中心插入会在另一侧产生错位。检查栏杆是否伸入柱内。 | 分别实量柱宽、柱墙错台、两扇门洞、北窗或邻窗净宽、栏杆转角间隙及侵入。变动项目关闭后再核平台与梯段净距。 |
| 座席与独立小件 | 在绘图清单中写明每一侧的件数及座面朝向。图库块先核正面、基点和左右手，再旋转或镜像。 | 把原图和纯线稿按同一方向并看。逐席核朝向与座位次序；特别查桌端、桌角、阳台椅、图案内侧可能漏掉的短凳。模糊构件写明推断。 | 量实际块占地，检查可用侧、拉椅方向及通行。整组家具平移时核邻门和柜前净距。 |
| 桌板、柜体、异形附件和共边 | 指定承接部件、被接面及预期接触的那一段；部分靠墙的端面可分成接合、露边与安装间隙。 | 原图用于判断大致朝向和应接的一侧。像素和阴影常不足以分辨很小的预留，结合块图例和功能写明推定。 | 从块变换后的真实线取桌板、柜背或端板，再从邻柜、墙面或门垛取对边。复量双方重合的实际区间。装饰曲线、家具外包框、嵌入式电器轮廓或邻近门轨不能代替承接面。 |
| 未标尺寸链 | 锁定两端、共有基准与横纵明标。按使用和构造选值，改同源尺寸链，连带更新量尺。 | 比对分段刻线、对侧可见齐边、同类洞口与家具布置。图片自身的比例偏差及多个控制站误差分别登记。 | 原生回读，按真实端面复量各段、总长和一条不同的相邻约束。逐一核重复、反向及隐藏层检查尺。 |
| 控制身份与实际墙厚 | 每个刻线登记墙面、中带、洞端或datum；共墙只建一套物理面。 | 源图无工程轴网时，不把新增线当原设计轴；端面不唯一就保留候选。 | 标注值、定义点及真实面分验；重叠墙求并集后量厚，保留交叠和并集证据。 |
| 开放入口与空间净距 | 先固定实际净区及边界身份，再放门图符和家具。 | 查开放书房是否被封、设备凹位是否丢边界、栏杆是否改墙。 | 同一截线量实际墙／框／门片功能面；净区求墙材侵入。缺边界记缺项，不用邻墙延伸或名义轴距补值。 |
| 真实纸面 | 房名放模型，图框、图签和图例放纸空间；统一英文图层编码、比例、符号、线宽及字高；标注用非白色。 | 整页看信息和层次，正常阅读局部看最密文字、门弧及留白。 | 清点各层各空间的实际实体，删除新建图的真空自定义层；从同版回读导出PDF，实量纸幅和已知线长。几何通过而纸面失败时仍返修。 |

## 修正记录

每个问题记录房间、对象、最早可预防的步骤、实际发现方式、原图局部或实量依据、改动和受影响的相邻部件。复核落在最终 DWG 的实体上。实际共边只有端板的一部分时，按测出的长度修订台账；原模型位置有充分依据时可原位保留。登记使用的原图库名、块名、图块是否按项目墙厚和洞端作了适配。

原图先独立枚举全部本案对象，再填检查结果；不套用历史固定条数。结构稳定后再放家具，同版同哈希回读可复用；几何、布局或版本改变使相关旧结论失效。已知失败先报，源图读数不确定性与CAD贴合精度、施工容差分开。每案只在作业目录留一份[短复盘](experience.md)，通用经验不由作业脚本自动追加。

137㎡ 实测的修正与用户确认记录见[验证范围](production-validation.md)。
