# 在原图上普查整间房的入口

适用于读图者可能一起漏记入口、房间看似封死、相邻房间通行关系不清的情况。脚本沿房间每条边从头扫到尾，也搜索墙的两侧。作者标注的门表、开口端点、门铰和裁好的门小图不参与搜索。输出是复核材料。脚本只读原图，不会改图、开墙或生成 CAD 门。

## 复用现有观察

已有 `physical-rooms.json` 时可以直接运行。脚本只取室内房间的编号、开敞状态和 `seeds_px` 地面种子，默认从 `source_to_mm` 读取横纵比例。外部、门表、门间连接和开口位置不参与扫描。

```sh
python scripts/survey_room_entries.py original.png physical-rooms.json \
  --from-physical-rooms --out review/room-entries
```

工具从每个种子向四方找有一定长度和宽度的直墙色带，兼看门垛两侧。推定的房间框在报告中标为 `seed_estimate`。对照原图检查它是否覆盖整个房间。缺一边时，工具暂取该方向图像边界，并记入 `seed_bounds_found`。超出暂定框的其他地面种子列入 `uncovered_seeds_px`。凹形房间、开放客餐厅或有多道隔墙的房间可能选错边。这时可改用已有的完整轮廓。

已有 `source-reading.json` 时，选出四条边都贴近整间房墙线的 `regions[].id`。下例的两个编号需换为实际编号。工具将原有裁框的半开右、下边界转换为图像像素。**只为看清局部而留白的宽松裁框、门口裁片和跨房间区域不能当作房间边界。** 它们的中心也未必是室内净地面。此时请用上面的地面种子，或沿已有轮廓给出房间边界。

```sh
python scripts/survey_room_entries.py original.png source-reading.json \
  --from-regions bedroom_a bath_a --mm-per-px 21.2 21.0 --out review/room-entries
```

自备房间框时，可用 `rooms-only.json`。坐标均取自按 EXIF 方向显示的原图，向右为 x，向下为 y。矩形两端均为图内像素，约落在墙线上。每个房间只需一种几何。正交凹形房间用按顺序排列的折点，也支持同样顺序的首尾相接边段 `edges_px`。地面种子可写为 `seed_px` 或 `seeds_px`。可以一起提供所有相邻房间，工具会显示预测门扇两侧落在哪些房间。

```json
{"rooms":[
  {"id":"bedroom","mode":"enclosed","box_px":[80,64,250,220]},
  {"id":"hall","mode":"open","polygon_px":[[80,220],[250,220],[250,300],[160,300],[160,265],[80,265]]}
]}
```

```sh
python scripts/survey_room_entries.py original.png rooms-only.json \
  --mm-per-px 24 --out review/room-entries
```

单个比例值表示两轴相同，可传两个值分别给横、纵轴。正交图支持尺寸不同的像素比例。图中有剪切或非正交墙时需另做原图复核。输出目录须是新的或空的。默认弧半径搜索范围是 300–1250 mm，覆盖常见单扇和较短的子扇。可用 `--radius-mm MIN MAX` 调整。较粗房间框默认在标线和拟合宿主两边各搜索 300 mm，可按原图误差适度调整 `--tolerance-mm`。若唯一模糊处是一面墙，优先改正该房间边界，避免把相邻平行墙也纳入。

## 看图与判读

先打开 `room-entry-survey.json`，按 `rooms[].sides[].card` 查对应的 `R01-S01.png` 等图。下标依照录入房间及周边顶点的顺序。每边都有一张图，包括没有候选的边。每张图的三个视图使用同一片原图。

1. 左图保留干净原图。检查门扇是否连到门垛、是否进到合理的相邻空间。
2. 中图用蓝线表示有宽度和连续长度的墙色色带；紫点和绿点分别表示弧、扇线上读取到的像素。门洞内若仍有连续实墙，不能判为可通行。
3. 右图显示拟合的四分之一圆弧和打开的扇线。两扇的闭合端接近且门轴相反时才列为互补双扇。橙线只表示墙色色带之间有间断，并未在该位置画预测门扇。

报告给出弧的分段支持、扇线支持、弧两端延伸对照、扇尖外延、门跨内色带比例、两侧墙垛和空间跨越。标准单扇候选需要独立弧心拟合、分布在弧上的线迹、扇线、沿同一方向的门垛和墙带缺口。邻窗可能仅留短门垛，因此保留一侧有支持的弱宿主，实际类型仍需核对。圆桌或台盆的连续圆纹、家具直边继续越过扇尖、只有门槛线或弧形文字标注，均不能凭单独线索认定为平开门。

| 候选或状态 | 在原图上核对的内容 |
|---|---|
| `arc_leaf_and_host` | 弧、扇和宿主线相符。检查墙垛、相邻空间及方向。 |
| `complementary_swing_traces` | 两套弧扇线索。查看两扇宽度和共用洞口。 |
| `short_leaf_trace` | 很短的扇形痕迹。查找配对主扇、家具或注记。 |
| `arc_leaf_host_unresolved` / `arc_leaf_room_crossing_unresolved` | 弧扇可见，局部边界或两侧房间待核对。 |
| `partial_swing_at_band_gap` | 墙带间断处仅部分线索吻合。回看原图或补取清晰图。 |
| `band_gap_no_swing` | 色带间断且无可靠门扇。可能为敞口、缺绘、被遮挡或不同墙色。 |
| `gap_with_linear_ink` | 间断内有直线，检查窗框、推拉构件、门槛或图案。 |
| `no_retained_signal` / `host_and_entry_unreadable` | 无足够入选证据。该边仍需读图；不能据此补一圈实墙。 |

每边默认保留最多两个不同位置的弧扇候选，另保留最多两个色带缺口。预算优先保留可相互闭合的双扇和高支持线索；同处重叠的弱解释会收敛。另有位置超过预算时，报告会记录数量，可将 `--per-side` 调到 3 或 4。整间封闭房间仍无入口时，逐边查看原图，包括图上标为无信号的边，复核推拉门、折门、洞口、藏于墙色的扇线及房间框。图示真实敞口时，可以有通行关系而没有门扇。没有可读线索就记为待核，不向墙体或门表写入推测几何。

目前搜索与图上水平、垂直墙相接的约 90° 平开门。极低分辨率、强压缩、斜墙、画成斜线的半开门和无弧画法都可能漏检。分析统一到不细于 24 mm/像素或较粗的原图轴比例；小于约 9 个分析像素的半径不能可靠验证。既有尺寸、宿主、窗及采光资料有助于人工定案。候选分数不是命中概率。

当有宽度的窗框、门槛和短墙颜色相同时，整条宿主可能被读成连续色带。原有弧扇检验未给足线索时，工具加查门扇尺度的淡弧。它在局部提高对比度，遇到重复的斜向纹理时按测出的方向减弱长直线，再将相同两端点、弯向相反的两条弧放回**原始灰度**比较。至少五段中的三段须支持同一弯向，同时要求自由拟合的弧心稳定，并检查整圆、宿主位置及房间两侧。符合这些条件的线索只列为 `visual_curve_only_unconfirmed`，与其他弧候选共用每边预算。即使门槛与墙同色，也保留 `middle_core_fraction` 的原始冲突。

点击该候选的 `local_review_card` 查看同位置局部三联图。左图放大原图，中图增强细线，右图用紫点标出所取曲线证据，用橙色虚线标出同端点的反弧对照。非方形源像素按标定比例显示。卡片底部列出两条弧在原始灰度中的对比度中位数和支持段数。弱候选的预测图只画弧，不补画缺失扇线。缺乏曲向证据的墙不画预测弧。
