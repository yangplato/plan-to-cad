# 用已核实的俯视块和墙面布置家具

1. 从[室内平面图块库](plan-families.md)选与原图用途和占地一致的形状。核对座椅的前后、床的枕侧、坐便器的水箱及使用侧。使用者指定其他图库时从指定库挑选。库中无同款时选功能及占地相符的近似块，记录替代。找不到可用块时登记缺件。表里的数是块的几何实量；家具是否合理由模型自己的用途及人体尺度经验判断，无须查询厂家。
2. 使用 `place_family` 时，`back` 是背部在模型内的具体接触位置，`facing` 指向坐下、起身、床尾或柜前的真实使用侧。床头和柜背要取选定宿主房间朝内的**实体墙面**，即墙芯坐标沿正确法向偏移半个实厚；相邻窗、短垛、凸柱造成的边界变化要按最终切洞墙材检查。先从共同结构获得实际墙材、再放家具，不把图片上的家具背边直接换算成放置坐标。
3. 对一面墙的多件或转角柜，按[实际接触边的测量与吸附](wall-contact-fit.md)量直背整段。属于真实弧背、脚轮或端柱接触的，根据相应图块几何查切点；带较小端饰却有一整段应贴直背的床，不能仅凭端饰碰墙声称床头已贴。床背较窗垛长或跨洞时，先查看沿墙可用跨度、图上位置和家具尺寸，再选合适的完整体量或同侧位置。无法合理覆盖时记为真实冲突。不跨窗造墙、不用穿墙换取“零缝”。
4. 在临时图中仅移动一把餐椅、旋转一件有朝向的洁具或移动桌板。检查完整形体、前后方向、遮罩归属和其他件的位置。餐椅对坐按每个桌边的座位逐个布置；若需移动整组才能保证功能，应回看原图的桌心、通道和与墙的相邻关系。水槽、灶具和台面是不同部件，操作前方应当是可用地面。
5. 从已保存的读回 DWG 逐房、逐件填写完整宽深与用途判断。旋转的块用自身局部轴；整体外包与真实占用轮廓分开。模型给出的常规尺度是检查线索。只要物件用途成立、可正常使用且与原图兼容，即可记录为有依据的特殊尺寸。自动工具因遮罩无法量测时，去掉遮罩外伸后量真实块内实体；不要让单个可解释的自动测量例外变成整户漏检。
