# 家具和设备的完整尺寸与使用检查

整户含家具时，逐房间清点原图中受托范围内的每一件活动家具、固定柜、洁具和设备。依据轮廓、用途、人体尺度和相邻空间作判断。下面的数字是普通住宅成人家具的经验参照，单位为毫米，不是强制标准。先确定物件是什么、哪边供人使用，再看数字。个别物件落在经验区间，也可能与本户型冲突。

## 逐件清点和实量

1. **先看原图。** 给每把椅子、每张小几、每组柜体、每件设备独立编号。写明房间、亚类、朝向、遮挡它的物件、应贴哪条边或应留哪侧使用空间。组合餐桌的每个座位、转角沙发的贵妃位、柜上的台盆或水槽仍分别查。模糊处标明可见证据及暂定用途，保留漏画、错类、模型多画的对象。
2. **从最终 DWG 复开并读回，或重读已保存的 DXF。** 从原图清单找到模型里的句柄和块内对象，反向核查两个家具层和其他层可疑物件。整户表至少记“房间/编号｜亚类与使用面｜原图露出部分和遮挡关系｜读回句柄/块内路径｜模型完整宽×深｜参考依据｜关键净距/承托实量｜结论”。多件同款仍逐件登记。图纸版本变化后更新受影响的行。
3. **分开记录图上露出多少、实物完整占地、活动所需净距。** 在临时副本隔离图块，或把被压在桌下的椅子单独移到空白处查看；同时核对原位置。完整占地包括到最外侧的椅背/椅脚、床框、柜门面等适用部分。床垫、椅座、盆内净空、包装尺寸、套组外框不能代替整件。以家具自身方向量宽深。柜沿正面量长，垂直柜背量进深；坐便器由后靠面量到前端。原位旋转、镜像、嵌套、非等比缩放均要计入。若块内部斜放，在其真实边上建立局部轴。异形物件分段实量或取实际轮廓。去掉文字、引线、门扇示意弧和装饰遮罩等非实体的外伸，记录取边。
4. **用原位动作判断。** 从交付对象取实线或闭合轮廓，核实实际接触边、最窄净距和受阻点。椅子在桌下允许合理重叠；验证抽出后可坐、椅背不侵床、通道可用。区分桌面与桌腿、床架与可悬挑床品、台面外缘与可开孔区域、墙面与门套。矩形包围盒相交只用来定位疑点。不同高度投影可重叠，需有高差、构造或原图证据。如高度不可识别，记待核。

## 按亚类初判，再看本案能否使用

下列为量级示例。表中“宽×深”按物件自身方向；床具另标宽×长。经验值供没有明示规格的平面重建。不可为追数值而拉伸图块或改墙，也不能用“特殊款”解释没有证据的半件或穿插。

| 亚类 | 经验参照与易错轴 | 在本案要实查的动作或边界 |
|---|---|---|
| 普通成人餐椅、书桌椅、扶手椅、凳 | 普通无扶手餐椅完整约宽 400–550 × 深 430–600；有扶手餐椅常更宽。带脚轮办公椅常约 550–750 × 550–750，按脚轮或扶手最外点。单人休闲扶手椅约 600–950 × 650–1000。无靠背小凳可约 300–450 见方，儿童椅、折叠椅另判。 | 确认椅背方向、座面是否完整；桌下遮住的座面仍可随椅一同移出。按“收拢、拉出、坐下”的实际位置看椅后余量及与床、门扇和相邻座位的关系。书桌椅不要因画得小而认作凳。 |
| 桌、几、台、沙发 | 4 人长方餐桌可约长 1100–1500、短边 700–900；紧凑桌、圆桌、伸缩桌按座位排布另判。普通成人书桌常深 500–750。双人沙发可约宽 1350–1900、深 750–1050；转角、贵妃位按分段深度。 | 餐桌逐边看桌腿、每席宽度、进出及背后过人；书桌能放脚和就坐；茶几、边几、电视柜、装饰几按用途另量，避免与椅混淆。 |
| 床、床头配件 | 成人单人床垫常约宽 900–1200、长 1900–2100；双人床垫常约宽 1350–1800、长 1900–2100。框、床头板、软包和外沿可加大总占地。 | 核床头与墙、床侧或床尾出入、柜门/抽屉、床边几。榻榻米、儿童床、上下铺、高低床分型；原图只露床垫时另推并注明床架。 |
| 衣柜、薄柜、收纳 | 普通横挂成人衣柜成品总深常约 550–650；正面抽拉挂衣、叠放、书柜或鞋柜可浅。书柜、开放格常深 250–400，普通平放鞋柜约 300–400，翻斗鞋柜可更浅。柜身、门板、拉手、轨道、净内深分别说明。 | 识别挂杆方向、叠放、鞋位、门型；从柜背到正面量。柜内能否放置相应物品，房间一侧能否开门或拉出抽屉。转角柜逐肢量，连柜按进深或用途变化分段。 |
| 地柜、台面、嵌入水槽和灶具 | 普通厨房工作台完成面深常约 550–650。柜身、面板、台面前沿和设备开孔是不同界线。薄边柜、岛台、吧台、双排和特殊设备另判。 | 水槽、灶具逐件与实际承托台面及柜体对位。按安装方式查看盆体/开孔投影、支承边和柜内空间，量最小边距或越界量。查设备开启、操作侧是否站得下、转角和相邻门能否使用。独立、挂墙设备按原构造，不强套台面。 |
| 坐便器、浴室柜、洗面盆、淋浴和浴缸 | 普通落地坐便器含水箱外形约宽 350–450 × 前后深 600–800；壁挂、短身、一体机另判，暗水箱的设备墙另占深度。浴室柜常深 400–550，小型洗手盆或薄柜可以更浅。 | 坐便器量全体，不把座圈、排水坑距当总深。查坐向、两侧和前方能否坐下起身、是否与门扇相撞。盆/柜逐对核安装方式与支承，淋浴核门口和净区，浴缸核可进出侧。 |
| 洗衣机、冰箱、其他家电和附属物 | 普通前开洗衣机机身常宽约 550–650、深约 450–700；薄机、双桶、上开另判。冰箱按单门/双门/嵌入式，家电按机身、把手和配管位置分别量。 | 机门、抽屉、散热或接管的可用侧须与相邻柜、墙和门相容。洗烘叠放分别点名并记为上下叠放。其他保留物件按用途另列，例如钢琴、阳台家具、花架。没有独立尺寸依据时，仍需给出实量和使用判断。 |

**净距按动作量。** 把椅从桌边移至能坐下的位置，量椅背到下一件家具或墙面的最小距离；若还需背后通行，另量剩余通行带。卧室量床框至柜前或椅背；平开门查真实扫掠区，抽屉/设备门查打开后的剩余空间。选用经验动作尺度时说明适用人群和使用场景。图源无法给出人体姿态、安装预留或施工实际，结论限定于图示条件。

## 返修和证据

- **可用**须有相符的用途、完整实体尺寸、朝向和对应使用关系的证据。仅能估定的尺寸注明“按使用推断”。只要判明该推定在本户型合理即可，直接按模型已有的家具与人体尺度知识评判，不查询厂家尺寸。
- **需返修**用于已查实的漏件、错类、半件、明显畸形或无法使用。例如移出后只有椅背和局部座面；完整椅身进入另一件不能共享的床架实体；嵌入水槽的开孔越出承托台面；普通横挂衣柜的实际内深连成人衣架也容不下。记录冲突的两件对象及量值，补全实体、纠正轴向、改选亚类或调整本案允许的未标位置。确认拖动时整件一起移动。不能用“原图画得小”“可能特殊款”把已知缺陷改成待核。
- **待核**用于证据不足。例如无法判断浅柜是书柜还是横挂衣柜、无法还原遮挡关系、无法解码对象。写清缺的是哪一条证据。落在区间外而能通过原图、功能和实量解释时，保留并写理由；单个经验值不足以判失败。
- 修改后重新保存、复开，复测该件、全部同型件和直接相邻物件。反查承托台面、墙边、门窗、柜门、床侧与通道；固定结构先后两版应能对位。如确实需要改已标尺寸、承重墙或布局，记录局部实量与影响，由用户决定。汇总应查、已查、需返修和待核数量。记录本次读回文件和实体定位，避免把上一版结果套用到新版。

辅助命令见下节。程序的零退出码只说明它读出了选中图层的可解析插入外形；整户结论还须完成上述逐件核对。

## 取得块自身两轴的实量

用含 `ezdxf` 的 Python 从复开后的文件读取。用实际图层名替换示例。

```sh
python scripts/measure_furniture.py 读回.dxf --layers 活动家具 固定家具及设备 > 块实量.json
```

`block_axis_extent_mm` 是放置后沿块自身 X、Y 轴的几何外包，`world_axis_degrees_xy` 给出对应的世界方向。识别前边后才能把二者写为物件宽、深；块内斜置时另用实体边定轴。程序解析嵌套和镜像，曲线取近似路径的极值，遇宽多段线、阵列、剪裁或未支持的对象列 `review`。有遮罩、辅助线、组合套组、散图元时，在临时副本单独选取实物边界再量。本工具不会识别少画的座面，也不会判定椅子是否能拉开。按完整清单对应每条结果，保留另测证据。

**复测样例。** 在任意新临时目录运行下列命令，生成一个宽 460、深 500 的测试外框，经镜像、缩放、旋转后读回。外框仅用于已知几何的复测。

```sh
python - <<'PY'
import ezdxf
d = ezdxf.new()
d.units = 4
for layer in ("活动家具", "固定家具及设备"):
    d.layers.new(layer)
b = d.blocks.new("demo")
b.add_lwpolyline([(0, 0), (460, 0), (460, 500), (0, 500)], close=True)
d.modelspace().add_blockref("demo", (1200, 830), dxfattribs={
    "layer": "活动家具", "rotation": 37, "xscale": -1, "yscale": 1.2})
d.saveas("example.dxf")
PY
python /实际技能目录/scripts/measure_furniture.py example.dxf
```

应读到 `block_axis_extent_mm: [460.0, 600.0]`，世界轴方向约为 −143°、127°。若模型内部只画 200 深的座位，程序仍会如实列 200；与原图遮挡、完整物件及使用空间合查才能发现半件。
