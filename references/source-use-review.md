# 在建模前独立确认房间能否关门、物件能否移动

普通整户作业由绘图者和独立审图者分别读图。专门测试不同观察者的识别能力时，可另派一人仅凭原图核对用门方式和逐件家具，并在交换判断前封存各自的记录。每组生成一份 CAD。已有同一张原图的独立观察记录时，保留其来源。

## 每个房间走两遍

第一遍，从住宅入口走进各房间。独立记录每个入口的两端、两侧空间，以及什么构件能把这里关上。第二遍沿房间边界回走，检查相邻的实墙、固定小窗和活动扇。原图像素向右、向下为正。

- 平开门分别找铰点、开启后自由端、弧线。把铰点放到另一门垛，试画第二种读法。查原图哪一种能同时解释扇线和弧线。判断门把侧、扇打开后靠哪面墙。
- 推拉门看导轨之间是否有错开的独立扇边，标出重叠区、两端收口及相邻固定框。大面积透光或过道较宽只能作为选型线索。
- 对敞口，检查两侧的私密、通行或防风雨需求及能实际关闭空间的其他位置。墙线中断只说明有洞；闭合方式还要看原图符号。来源模糊时保存能支持的两种解释、各自证据和选择理由。

把结果写入一份 source-reading.json。用 independent-source.md 的门户格式。between 中写两个空间。basis 指出依据来自哪里。可将不同解释写入 alternatives。在 CAD 自检时，也用这份独立登记检查复开图中的实际扇、轨、铰和所通向的房间。

## 逐个实物读图

从房间入口沿四壁绕一圈，再看房间中央。给每个能单独移动或安装的物件留一个位于它可见轮廓内的原图点。两张床之间的一个边柜只有一个编号。一张餐桌和四把椅子有五个编号。同一件床的枕头不另计一张家具。L 形组合柜注明两翼的拐角、方向和各自接触的室内墙面。

填写 furniture-source.json。单件有 id、room、use、role、anchor_px、group、attachment、evidence。可在同一行加 visible_parts、axis 或 alternatives。role 用 movable、fixed 或 ancillary。attachment 用 freestanding、built_in、services、secured、architectural 或 unresolved。家具紧贴墙只能证明它的位置。把床头旁的独立小柜算作活动家具需要观察独立柜身，把柜认作定制件需要看连续背边、跨墙布置或明确的安装关系。按实际使用核对逐件关层。隐蔽连接或某个产品的确切尺寸可以保留为推断。

选择图库图块时核对俯视轮廓。椅子应能找到坐面和靠背，柜/桌的上投影与正视腿脚区分。技能内置的已核俯视族可用 `python scripts/place_plan_families.py --full` 列出。圆边几、圆茶几、矩形和圆形脚凳、休闲单椅及长凳均有实际俯视几何。按原图选择其用途，再以居住常识判断本图所需尺寸。图库原块的图面跨度仅供了解形状比例。

合并三份读图时保留各自已封存的原判断。按洞口位置或逐件源图锚点配对。遇到分歧时，重看对应原图，以能解释全部可见关系的判断建图，记录未采用读法和原因。合作者只看原图。外审首次看到 CAD 时，作者已经正式提交。

仅评首稿时，外审发现的问题进入本轮记录。将能够迁移的原因改入下一版工作方法。从同一原图开新的独立上下文。每位作者从空白再做一张，重新冻结并匿名核验。按试验开始前登记的标准比较每个人的首稿与整组合格数。
