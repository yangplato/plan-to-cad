# 从真实使用边量正净距

先看原图，指出人在哪一侧、哪一段边可以实际使用、什么物件会挡住，以及仍可调整的局部范围。沙发可按每个实际座位分别登记，测大腿前方到矮几的间隔。只在侧边的几另记用途。坐便器前方、左侧和右侧各是一条用途，按本案需要分别登记。台前备餐、站人操作和开柜门也分开登记。开启柜门时用本柜扇、抽屉实际开启量和人体站位判断；本工具只能测沿所给方向的净带。铰门转动和复杂姿态另查真实扫掠。没有可辨前后时保留待核。

用家具构造、原图和相邻实物为每项选定深度、连续宽度和作用高度。记录这是原图所见、 CAD 实量，还是采用的使用经验。数值只对这项活动有效。实际净距由保存文件中每条截面的真实边得出。不得从示例复制净距充当通用下限。

## 整户先跑一次粗查

已有 `run_first_plan.py` 任务表及其出图目录，直接运行：

```sh
python scripts/screen_front_groups.py job.json 已建模型目录 > 座前实量.json
```

也可以调用 `screen_front_groups.screen(doc, scene, schedule, objects, inventory=None, bindings=None)`。第四个参数是编译结果 `products["objects"]` 的句柄表。命令自动加载任务表中的原图独立家具清单和绑定（如有）。无需画使用带或登记每一条实体路径。

逐张找沙发、组合沙发的独立模块和休闲座椅。先看本件的 `family`，也可从原图清单的用途、对象的 `function`、图库块名或编号识别。看不出的自定义轮廓只需在该对象补 `"use_role":"sofa"`、`"sofa_section"` 或 `"lounge_seat"`。几或柜可用 `coffee_table`、`side_table`、`low_cabinet` 补用途。朝向优先核对原有 `back_px` 和 `toward_px`；缺失时补 `"facing_px":[[背部原图x,背部原图y],[前方原图x,前方原图y]]`。内置族或经过统一转换的图库块能从实际插块矩阵独立重取朝向。若与编排方向冲突，结果同时给两个方向和角差，截面沿回读的块朝向计算。看不清方向的异形整组、可朝多个方向的独立座位，分清每个真实坐面后走下方精查。

在每个座位的 `candidates` 查看面对的每一件物体、句柄、跨多宽、最近和最远多远。`sections` 的每一段给左右两个端点在实图的位置、相应真实间距和这段横向宽度。台几横跨的每段连续宽另列 `front_spans_mm`，最长一段为 `continuous_width_mm`。遇到凹面台阶，端点值从本区间一侧量，台阶处会出现两个不同深度。几仅在侧方、完全在后方、或双方已登记为不同房间另列。已登记的直接敞开连通房间保留跨房间候选。房间未知时所有投影重合的前方物件都会列出，远处隔墙或隔着另一件物体的也可能出现，按实际房间和相互用途核对。

`closed_projection` 表示回读图线可形成完全包住实线的闭合投影，内部包含刻线、高件或架空时须看构造。`strokes_only` 表示仅量到能读出的真实线。它们都不能自行判定人的腿能否伸进去。没有候选、图线没有相撞、几处于更高位置、存在极小正间隔都要结合原图判断。粗查不会按统一距离打分。实际间距疑似不够、被窄构件局部挤占或仅在高度上错开的，使用下方精查。

## 精查命令与输入

```sh
python scripts/check_use_clearance.py review/native/readback.dxf --inspect 92 A3
python scripts/check_use_clearance.py review/native/readback.dxf 局部使用登记.json > 正净距.json
```

Python 可从 scripts 导入 `audit(doc, registration)` 与 `inspect(doc, handles)`。依赖 ezdxf 与 Shapely，沿用同目录的图块和结构回读工具。传入 `ezdxf.readfile(...)` 的毫米模型。正式核查使用由本次 DWG 原生复开后导出的家具全开 DXF。命令返回 0 表示登记用途已具足够连续宽度、所查实体间无未解释的穿插；1 表示有待核或需调整项；2 表示输入无效。JSON 同时带本次回读文件哈希。

以下句柄、实体与数值均为虚构。实际工作先检查本次回读的图层、句柄和块内路径。相同图块的多个实例可以共用实际定义路径，但分别登记各自句柄、位置和用途。

```json
{
  "scope_basis":"原图客厅这四点圈定的座位、几、墙和相邻实物已逐件对应。",
  "scope_wcs":[[0,0],[4000,0],[4000,3100],[0,3100]],
  "physical_layers":["活动家具","固定家具及设备"],
  "movable_layers":["活动家具"],
  "wall_layers":{"实体墙":"fills"},
  "objects":[
    {"id":"沙发","handle":"92","kind":"movable","basis":"原图背靠西侧，块中核对了坐面和两侧扶手。该例三者在同一闭边内，地面至坐面前方存在实体。",
     "parts":[{"id":"座身","paths":["85/62"],"z_mm":[0,700]}],
     "interior_detail_basis":"其余均为该实心座身内部的绗线。"},
    {"id":"几","handle":"A3","kind":"movable","basis":"原图沿座位前侧布置。块上可辨封底矮几，地面至几面为实体。",
     "parts":[{"id":"几身","paths":["9F"],"z_mm":[0,420]}]}
  ],
  "uses":[
    {"id":"双人沙发中间座位的腿部空间","object":"沙发","part":"座身",
     "forward_local":[0,-1],"source_direction_wcs":[1,0],"max_axis_error_deg":12,
     "span_mm":[-500,500],"use_z_mm":[0,600],"required_depth_mm":340,
     "required_width_mm":600,"lookahead_mm":850,
     "basis":"从靠背辨出坐面朝东。原图可见一处坐位面对矮几，本次按一人坐下活动双腿取宽深。"}
  ],
  "repairs":[
    {"object":"几","axis_wcs":[1,0],"range_mm":[-25,180],"step_mm":5,
     "allowed_footprint_wcs":[[1200,450],[2600,450],[2600,2350],[1200,2350]],
     "basis":"结合原图中几的完整宽深和周围留白，允许沿这一轴在此范围微调。"}
  ]
}
```

- `physical_layers` 应包括局部所有可能占地的家具、设备、立柱和其它实物所在的非墙层。范围内这些层还有未认领的图元会报覆盖缺项。对合成小样或单独逐件登记构造边的局部，可省略 `wall_layers` 并给 `structure_basis` 说明实墙如何覆盖。通常以建模账的 `wall_layers` 解实际墙材；存在其它非墙填充图层时沿用同账 `nonwall_fill_layers`。范围内的可开启房门、滑扇等必须纳入整体判断。缺少它们的开启证据时在其它检查中补查。
- `--inspect` 列出实际构件路径、端点、边界框和是否闭合。块内递归变换保留基点、缩放、镜像与旋转。一个部位可由多条首尾相连的真实线组成。每组须得到唯一本体闭边。模型空间独立闭边用 `"paths":["self"]`。不要用外接矩形或凸包凑边。凹边可测。未给用途的图线只有在实物实体边内且写明内部刻线等依据时才能忽略。伸出轮廓的把手、侧板、脚位应分别登记。有孔轮廓、复杂开架或无法可靠闭合的线图保留待核。家具需在实际全开图层核查。
- `z_mm` 是部件在共同地面的实体高度区间。桌板与支脚按实际构造各自登记。只有下方真实开敞才可按上下分层处理。无法判定时用 `null`，会给出未知高度情况下的可用宽度上下界。单纯猜测的高度不得作为排除矛盾的证据。
- `forward_local` 指块中人工识别的实际使用正向。`source_direction_wcs` 从原图中人所面向的方向独立取得，转换到 CAD 世界坐标。方向误差超过本项容差即标 `wrong_direction`。默认容差 15 度，也可按本案证据指定。独立模型空间闭边的局部轴同世界轴。侧向用途填该物件相应外侧方向。两条方向若出自同一假定，程序无法证明设备朝向。
- 对每一用途，横轴取 `(正向.y, -正向.x)`；零点为选定部位沿横轴的投影中点。`span_mm` 两个有符号毫米数给出可使用边段。每一站从该处选定部位的真实最前沿量起。同一座身若扶手比座面前伸，给坐面单独取边，并把扶手作为同一件的其它实体部位。作用高度 `use_z_mm` 包含人体或活动部件真正需要的高度。`lookahead_mm` 控制截面向前实量的上限，默认是所需深度两倍。检查范围必须覆住所需使用带，超出范围会标待核。

## 看结果、改一处、再复开

`sections` 给出横向站号、实际使用边世界坐标、撞到的首个实物和命中点、实量净距。遇未知高度的障碍保留其状态。`clear_to_mm` 表示已查到的距离；`scope_boundary` 表示量到登记边界。宽度判断用整条真实轮廓和所需净带的几何交集，结合轮廓拐点、相交区间及其内部截面。很窄的一根立柱也会截断连续宽度。只选择几个均匀站点容易漏掉这种问题。

`known_clear_spans_mm` 是达到目标深度的每段连续横向区间。`longest_known_clear_width_mm` 是可证的最长一段，禁止把被分断的两段宽度相加。`longest_possible_clear_width_mm` 包含尚待辨明的高度或曲边误差。多坐位分别量，不把中间一个宽段替代两端坐位。`partial_clear_width` 仍须看哪一段被局部压住，只有剩余一整段满足登记所需宽度时才会出现这一状态。`physical_pairs` 另外列出物件间的实碰、已知上下投影及高度待核。高度不同、仅在使用边侧方、朝向不对、正前有几但间距过小，分别对应不同位置和处理方法。曲线经过 0.25 mm 离散，临界间距或接触需局部放大复看。

只有经原图确认的小区域可填 `repairs`。给允许移动的一件活动块、允许的平移轴、位移区间、步长及可容纳完整物件的世界坐标多边形。程序从最小位移起检查格点和区间两端。每次复算全部登记用途、邻物和实墙的交叠，并核整件沿途留在允许区域，未穿入新的同高实体。返回的是这条轴上已检查候选中的最小值。结构、固定设备和其它物件不参与移位。没有可行解时保留所有物件，复核朝向、选型、原图观察和采用的用途；涉及结构或已标尺寸的改变由委托方决定。建议不直接改图，需在源模型应用、保存、原生复开并重测。报告只覆盖登记范围及所述姿态，不代表全户验收。
