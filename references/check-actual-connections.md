# 从人和光实际经过的位置确定洞口

从每个房间内部出发。写出人从何处进入，从何处返回。卧室、卫生间或厨房如果图上有门扇，不能只画一段空墙或写成开放相连。客餐厅之间清楚的连续开放区域可合并。沿每段墙逐项登记通行和透光两种用途。人能走过去的移门要把实际两个空间连在一起；同轴相邻的固定扇或侧窗另记。没看到活动扇时，在原图上记录可辨线、光线或透明边框、墙端和两个区域，不按固定数量补门。

读图者只看原营销图，独立另存 `physical-rooms.json`。为封闭房间登记实际地面种子，L 形或门厅转弯处可登记多个种子。为各可通行洞，从洞两面附近各选一点，人能从该点正对洞走到另一点。两点各在自己的房间内，走向能区分横洞和竖洞。卧室远处的床中心不能代替局部接近点。按原图同时登记每个已确认窗框、移门扇框及开放边；一根轴线上可有多个种类。原图房间或开口本身不清楚时说明依据。字段与合成例见[实体房间和门洞](physical-room-connections.md)。

作者与读图者先各自保存原图判读。同组交接时给每道门、窗和自由边做一张局部图。左起为原像素、局部明暗增强、边缘增强。平开洞另有候选对照。依次检查每张，在生图之前登记对扇形、两端与母轴的最终判断。两模型同意并不能替代查看原图区。弧线弱的门用实体墙端、局部两侧接近点、开放端及地面连续性共同判定。颜色调整只帮助看清线；图内没有的线仍属推断。

```sh
python scripts/read_portal_patches.py 原图.jpg 自判.json 同档原判.json 洞口局部 --band-px 本图像素读差 --mm-per-px 本图比例
python scripts/check_portal_rooms.py 结构回读.dxf checks-mm.json physical-rooms.json --json 房间报告.json --svg 房间与洞口.svg
```

这个检查在当前文件的墙材上临时封闭各门窗。程序用每个种子定位连通的地面，再查门的两侧实际邻接哪两个空间。局部接近点用于比较错轴的候选及实际通行。对“封闭卧室却和过道连成一片”“门洞通到另一房间”“本洞的图符画在邻洞”等结果，回到原图查看局部。窗与框除了图层出现，还须在本洞找到真实图符。自由框或墙边不能围出可测试区域的情形要另列“待核”。查完每处，保留原证据和本次解释。

独立房间编号与建图编号可以用别名对应。只转换名称，不平移见证点，不替换原图读出的类型。若一种原判与实际源图冲突，将两套原点和局部图留在记录中。多个候选都解释得通时保留不确定性，由图形和通行逻辑作取舍。

用原图像素反查在两次读图中都可能遗漏的细框，尤其是门垛之外或窄边上的连续平行线。先逐页看 by-opening，每张都有本洞和两个相邻边段原图。查看 before、inside、after 三组候选，再按图证决定原判中的敞口、固定扇或移门是否成立。

```sh
python scripts/find_frame_bands.py 原图.jpg 细框检索 自判.json 同档原判.json --mm-per-px 本图比例
```

沿室内与室外的全部交界追踪挡风雨的围护。室内地面与室外看起来连贯时，检查线轨、断面与不同地面的收口。宽洞两侧有墙垛且中间有连续细线或分扇痕迹时，考虑可关闭的玻璃构件。若认作永久敞口，记录实际挡风雨的边界在哪里，或记录该空间本就向室外开放的图证。窄固定边扇能透光但不能供人穿过。从源图看不清轨向时保留门类及其位置，把具体轨向记作推定。

在完整工作模型上运行 preflight_first.py 时，可附加 --reader 同档原判.json、--band-px 本图读差、--room-witness 已映射编号的独立房间见证.json 和 --contact-job 靠墙实物.json。程序逐份查独立标记的窗/移门是否出现在本洞，按真实墙材验证房间分区，并对靠墙物件量毫米实缝。靠墙实物清单按库内床、直柜与两翼转角柜准备；每个源图要求贴墙的背边都有对象，空间内故意独立的家具给出用法依据。

对读回的已知小缝，用[背边复量与新副本修正](repair-wall-contacts.md)在可恢复的工作副本处理。修正时在实际 CAD 坐标中平移家具。不得将真实墙面的毫米值四舍五入到源图像素。完成后重新保存、复开、实量，不能拿修正前的 DWG 交稿。每个洞口的图符判定及其它等价画法见[按原图位置检查门窗](registered-frames.md)。

### 套内开放与住宅公共通道

从公共起居区走到每个卧室、卫生间的私用区域，逐段指出在哪儿可以关门。房内可能有开放衣帽区、小走道或敞开前区。床区通到套内前区的地面连续，并不能独自确认整套与公共走廊之间也是敞开的。遇有转角时，从两个房间各取靠近同一门的点，走一遍门前、门中、门后，另看首个能闭合的私密边界在哪里。真正的开放睡眠布局以明确连续空间和图上用途为据；如无法判定，保留原图局部和最符合使用逻辑的候选，在记录中给出理由。
