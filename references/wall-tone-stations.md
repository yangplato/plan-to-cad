# 按原图色段实量保存后的墙材

同一根墙的深浅分界可能画错，即使每段中心的颜色都正确。先沿原图墙芯记录两侧的连续色带，再对保存后重新打开的 DXF 量整段墙芯和实际分界。工具只读原图、读图记录和 DXF。它依据本图图例或制图者登记的深浅图层来比对。仅凭深浅无法判定实际结构性质。

## 输入与运行

1. 在原图两类稳定墙芯中各取若干内侧点，避开阴影、字样、抗锯齿边缘和窗线。按[墙芯采色方法](color-guides.md)填写 `samples`、粗轴 `a_px/b_px`、法向搜索范围和实测芯宽。母轴覆盖要核的整个墙段，两端可跨换色点。对一根长轴，至少核对每个稳定色段两端的原色。读图独立完成后再读取 CAD。
2. 将已辨认的 T 接、窗、开放边和干扰写入原图记录。两个相交方向都标轴，可自动列出交接带。已知色温变化、阴影或家具遮挡可在该轴补 `"review_spans":[{"span_px":[49.5,56.5],"reason":"shadow"}]`。这项直接写在输入导线或原图站表该轴下。需要自定义干扰带时，优先直接传导线文件；已有的 `fit_wall_guides.py` 站表只保留其原来支持的交轴、遮挡和确认洞口等字段。
3. 传入同一原图的导线 JSON 或已经生成的 `guide-report.json`。工具复查真实像素，后者还校验原图文件指纹。不要用 `scene.json`、CAD 拟合线、回读对象或历史人工图作为原图读数。横轴沿 X 向右，竖轴沿原图 Y 向下，坐标均采用正常显示的 EXIF 方向。
4. 另备配准 JSON。登记实际毫米图层名、原图至保存 CAD 的变换，以及没有参与拟合的控制点。可用总图角点或尺寸刻线检查偏差。选择远离本次换色点的控制点，尽量让其分布在图幅两侧。登记 `source_sha256` 可绑定原图。已确认的非墙填充层填入 `nonwall_fill_layers`。遇到未分类填充或无法解码的墙图元，结果列为待核。墙默认读取填充和配套闭环。只有实际表示双墙皮的已知嵌套环才在 `wall_layers` 按图层改写为 `nested_loops`。
5. 输入从磁盘读取的 DXF。验正式 DWG 时，用该版本 DWG 的原生回读 DXF。将 `--read-band-px` 换成本图重复读同一分界得到的单侧读差。可另给 `--normal-band-px` 作为墙心法向单侧读差。两个参数默认使用同一值。工具把配准容差按轴向和法向分别换算进允许带。输入像素读差不应重复计入配准误差。

配准格式示例使用虚构比例，横向每像素 10 mm，竖向每像素 12 mm。

```json
{
  "layers":{"bearing":"深色墙","partition":"浅色墙"},
  "nonwall_fill_layers":["固定家具及设备","活动家具"],
  "source_to_mm":[10,0,0,-12,40,850],
  "holdout_limit_mm":6,
  "holdouts":[
    {"source_xy":[220,50],"cad_mm":[2240,250]},
    {"source_xy":[10,10],"cad_mm":[140,730]}
  ]
}
```

```sh
python scripts/check_wall_tone_stations.py 原图.png 源图导线.json 原生回读.dxf 配准.json 临时/墙色复核 --read-band-px 1 --normal-band-px 1
```

输出目录应为空或尚未创建。打开 `wall-tone-stations.json`，按轴号查看同目录 PNG。整轴条带保留原色，竖轴转为上端在左。各换色局部图上方保留原色，下方蓝带表示源图允许位置，橙线表示已识别的 CAD 分界。短窗等无法读出原图换色点的位置没有蓝带。

## 读量测结果

- `runs` 按轴列出已识别的每个色段和各个待核区。两侧 `shoulders` 含带状原色样本的位置、中位 RGB 和最远样色距离。工具对每个原图像素站至少三条芯内扫描行复核颜色，两端必须有稳定带。短色条、单像素噪声、疑似透光双线、较宽的交接、标明的阴影分别保留原因。与稳定墙色完全相同且形状完全相同的遮挡，仍需看原图背景和图例。
- `normal_checks` 按站实量 CAD 墙的两个外缘、计算墙心偏差并汇总连续站。正值表示朝原图法向坐标增大方向。墙心偏出法向允许带、附近有多根平行墙或宽度变化可疑时，这些站单列待核。不会因为墙心整体偏开，就把整条墙报成错色。
- `material_checks` 用连续二维几何比较该色段整个轴向范围，法向取墙芯中央半宽。沿轴投影记录实际错层、无墙材和双层重叠的区间，即使偏差只出现在两个抽样站之间，也能定位。面积位于墙芯中央半宽之外的墙面、门套和轮廓须另查。`raw_other_tone_px` 保留原始错色区间，`decisive_other_tone_px` 扣掉两端读差，`other_tone_length_mm` 是这些区间的轴向长度。相互重叠的投影长度只计一次。
- `changes` 逐处分开列出原图两侧样带、`source_band_px` 与实际 CAD 换色位置。清楚的相邻像素以共边的半像素为分界。有短而连续、横向均匀、介于两样色之间的渐变时，使用两侧最后和最先稳定的像素边缘形成读差带。工具另加输入读差。根据三个墙芯内侧纵断面及整条带的材料范围核实 CAD 分界。正的 `signed_delta_px/mm` 表示 CAD 分界向原图坐标增大的方向移。若 CAD 断开、重叠或有多个无法归属的换色点，则列为待核。
- `sufficient_tone_evidence` 指对应结论在登记的墙芯测区内有足够依据。待核区保留原始候选和原因。色段内找到了局部错色时，只将明确的错色区间计入长度。三类退出码分别为 0（所测范围读差内）、1（至少一项已证实不同）、2（需复核或输入有误）。同一个含错报告还可含其他待核区。

## 如何修订墙段

仅当两侧原色带可靠、两侧墙芯对齐、回读墙材连续且没有重叠，分界明确错移或整段省略一次换色时，输出 `interval_edit_hint`。先对照母轴号、两侧区间及正向材料，再找到 `scene.walls` 中对应的既有实墙。已有两段共用的分点可沿既有轴调到实测读差带。需要新分段时，两段继承原来的墙心、厚度、各自外端做法，新接头使用同一坐标，内端不加延伸。若原墙对象是洞口宿主，先核对洞口净宽、宿主 ID 和扣洞关系；不能落实时保留待核。任何触及已标尺寸、墙厚、结构定性或房间布局的变更需要单独核实。工具只输出提示，改完须新存并重读。

## 虚构样例的量测记录

下表使用原图三段深、浅、深墙芯。清晰分界位于 74.5、154.5 px。沿墙每像素 10 mm，法向每像素 12 mm；原图读差各为 1 px，虚构配准的留出点精确重合，登记配准容差为 0。每个工况均新存 DXF 再从磁盘解码。

|工况|实量|依据|
|---|---|---|
|正确分层|两处分界均相差 0 px / 0 mm|整段墙芯与两侧色带一致；另用原图站表输入复查|
|第一分界偏移|实际 89.5 px，偏 +15 px / +150 mm；扣除读差后，浅色段 75.5～89.5 px 有 140 mm 错色|仅提示修订第一分界|
|整根墙心横移|各段法向 +2 px / +24 mm|仅提示核查配准或墙轴；没有材料分段建议|
|短透光端|145～154 px 有两条细线，10 个像素站|保留原色，第二分界无有效读数|
|省略中段|整个母墙只读到深色，原图明确存在中间浅色|报告两次缺失换色，可审阅两个分点|
|三像素渐变|74～76 px 连续混色，第一分界允许带 72.5～77.5 px，CAD 到中点差 −0.5 px / −5 mm|读差内|
|短色条、阴影、T 接|短条单列，标出的阴影 50～56 px，交接 101～107 px|对应区间待核，其他清楚处仍有独立结论|
|两端与中心均正确，段内夹有异色|浅色内 104.3～105.1 px 的小片错色，投影长 0.8 px / 8 mm|已由整段面积比对定位|
|竖直母墙|两处分界均相差 0，轴向比例使用 12 mm/px|沿原图 Y 向下登记|
|错配准|留出点残差约 439.32 mm，超过该例登记上限|停止比较，没有分色结论|

这些工况检查受控图形上的行为。实际项目仍需逐面检查不同背景、源图比例、采样质量、图例和原生回读实体。
