# 沿母轴一次读完各色墙芯

在正交营销原图上，作者独立取两类墙芯样点，圈出每根母轴从哪里看到哪里。工具按原图像素逐站横切两侧，寻找宽度和中心都相符的连续色带。沿同一母轴逐段识别两种颜色，保留相邻深浅交界、无匹配色的断段、细线、交点和短墙垛的位置。拟合结果是可编辑的首稿建议。

在工具包目录运行。使用已安装 NumPy 和 Pillow 的 Python。

```sh
python scripts/fit_wall_guides.py 原图.png guides.json 临时/墙轴
```

示意输入如下。坐标和参数只用来说明格式。须在本张原图另取样、量宽、标轴和定比例。输入的 `a_px`、`b_px` 是同一条水平或竖直引导线两端的原图整数像素。原点在左上，X 向右，Y 向下。JPG 采用正常显示的 EXIF 方向。

```json
{
  "samples": [
    {"material":"bearing", "points_px":[[24,40],[42,40]]},
    {"material":"partition", "points_px":[[74,40],[110,40]]}
  ],
  "defaults":{"core_width_px":[4,12], "search_px":4},
  "axes":[
    {
      "id":"H1", "a_px":[4,41], "b_px":[214,41],
      "keep_points_px":[[151,40]],
      "openings":[
        {"id":"D1", "span_px":[99.5,123.5], "kind":"open", "connects":["outside","客厅"]}
      ]
    },
    {"id":"V1", "a_px":[43,14], "b_px":[43,108]}
  ],
  "axis_intersections":[{"axes":["H1","V1"],"point_px":[42,40]}],
  "source_to_mm":[10,0,0,-12,0,1500]
}
```

1. `samples` 取无遮挡、非边缘的墙芯像素。每个样点默认取周围 3×3 像素的中位色。极窄墙芯可在该材料加 `"radius_px":0`。印刷或 JPEG 有色差可加 `tolerance_rgb`（RGB 欧式距离）。两类样色过近会限制容差；取到同一中位色会报错。按项目图例解释 `bearing`、`partition`。没有图例，在本案记录中说明这两层暂按图上深浅归类。
2. `core_width_px` 填正常墙芯像素宽度范围，`search_px` 是在粗轴两侧寻找墙心的距离。默认值对所有轴有效，各轴可另写。长轴应越过洞口、换色点和墙端，覆盖母轴可能出现墙材的全部长度。图外尺寸线区域可用 `plan_box_px:[左,上,右,下]` 裁定，四边均包含。已确认与墙无关的文字或家具可用 `exclude_boxes_px:[[左,上,右,下]]` 排除；`nonwall_points_px:[[x,y]]` 是负样点，落实芯时触发冲突，须回看原图。
3. 轴附近有两条平行候选时，可在已知墙芯内选一个 `anchor_px:[x,y]` 复跑。可选 `axis_intersections` 使用独立读出的横竖轴交点约束两条直墙的中心；输入交点应与已拟合的墙芯一致。轴上有明显错台或偏心变厚时，拆成两根独立引导线。工具沿每根导线使用同一 CAD 墙心。
4. 核对 `axis-001.png` 等彩条图。上方为原图条带；竖轴转置后仍从上端向下端读。下方第一条为原始色带判读，第二条绿色条为人工确认的净洞/开放边。图下数字是原图轴向坐标。到 `guide-report.json` 按同一轴号与站位查精确变化。每条 `observations` 记录连续像素中心的包含区间 `stations_px`，对应像素两端边界为 `span_px`，如 10 至 64 像素对应 9.5 至 64.5。相邻材料共用一个几何端点，原图上两个像素间的边界用半像素表示。
5. `stable_core` 满足宽度、站数和中心要求，进入墙建议。默认至少 4 站且长度至少为芯宽的 1.5 倍。`min_run_px` 可提高站数要求。`short_core` 始终保存在报告里。确认短墙垛后，给本轴加 `keep_points_px`，点在该垛墙芯内，重新运行便得到 `confirmed_core` 墙段。一个像素点状噪声一般也只保留为候选。仅在交轴内部出现、没有本方向墙身支持的色带不生成该向墙。一条连续墙跨另一轴时，仅在同色两肩均有足够墙芯，而且交点中心保留同色时连接。T 端可接至实际贯通墙面。
6. `no_sampled_core` 表示没有匹配样色，`review`、`junction`、`conflict` 和 `excluded` 需要人工识别。未确认的这些区域均不写实墙。房间地面、家具边或门槛若恰与墙芯同色同宽，像素不能独立判别。看门扇、框、弧线和房间通行关系，把净洞登记在本轴 `openings`，两端写连续坐标 `span_px`。洞即使穿过看似连续的墙色也会扣透。保留 `span_px` 顺序，后续门扇的铰侧 a/b 用这两个端点。门窗参数如 `toward`、`leaves`、`tracks_mm`、`panels`、`lines_mm`、`jamb_support` 按[共同建模入口](first-submission.md)传入。与墙无关的开放边用本轴 `open_edges_px:[[净空起点,净空终点]]` 留空。自由栏杆或独立框另按实际图符登记。
7. 有 `source_to_mm` 时，`cad-fragment.json` 中的 `walls` 和 `openings` 可一并并入本案的 `scene.json`。同一份变换下，水平墙厚用 Y 比例，竖直墙厚用 X 比例。每个确认的净洞产生一个恰好覆盖洞口的专用宿主，与同一洞口成对交给共同入口，从墙材中完整扣除。**不要单独复制墙表而漏掉洞表。** 洞宽沿本轴计，宿主厚度由相接墙段取最大值；两头都没有测得接墙时，补明 `material`、`width_px`，按实况填写 `jamb_support`，并核查是否应改作自由边框。无比例时仅输出 `pixel-fragment.json`，可先校正像素记录，确认比例后再生成毫米建议。
8. 补齐自行识读的房间净区、尺寸、门窗图符参数后，运行共同建模与保存文件检查。除门槛外，还要看短垛是否接实、另一方向的墙是否占用净洞、各房间是否可达。原色检测用 `scan_wall_cores.py` 的样色分类和寻轴；整幅遗漏须再用[独立原图普查](source-survey.md)及逐房目检。未标母轴、曲斜墙、被覆盖的实际材料、门的功能和开向不能由这些条带直接确定。
