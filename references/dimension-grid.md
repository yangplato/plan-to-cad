# 从尺寸刻线定位墙、柱边和洞口

在原图上逐条读四边尺寸。顺着尺寸界线向室内看，判断它指向墙中、墙面、洞端、柱边，还是一条只能定位的控制线。给每个位置一个名字。图上同一位置可由两条链共用。记录毫米数和刻线的原始像素。用同名位置生成构件和 CAD 标注。

只有原图明确给出工程轴号及对应依据时，才称工程轴线。否则记为营销控制线或构件面候选。不得把相邻数段全认墙心：逐点看同一截面的墙两面、窗框与洞端。多个取面仍合理时并列候选及影响，不只保留恰好等于标数的一项。分段合计另记为派生总长，不增加原图明标计数。

**有分段尺寸。** 设 `scene.dimension_grid.mode = "chains"`。每条连续的印刷尺寸链各占 `dimension_chains` 一行。使用原图的上下左右边和可辨的总长。两段尺寸之间有空白时分两行。共线但分离的尺寸段，用另一条链的同名控制点确定位置，或登记有依据的首刻线世界坐标 `start_mm`。不要用差额补一条原图未标的尺寸。

**只印总宽或总深。** 用 `"overall"`。每条总跨度只列首尾两个控制点和一个值。墙、房间和家具的中间位置按原图比例推定。只有一向有刻度且未传 `source_to_mm` 时，另一向暂按等像素比例。若保留了实测的独立仿射配准，另一向沿用该配准。

**没有印刷尺寸。** 用 `"unmarked"`。留空或省略 `dimension_chains`，在 `dimension_grid.reference` 填一段已知长度。例如，现场复测了同一开口的两端时，可填写以下记录。两端的 `controls` 定义与下文相同。

```json
{"kind":"known_length","axis":"x","controls":["门A","门B"],"value_mm":990,"evidence":"现场量同一对洞口端面，990 mm"}
```

只有墙厚可暂估时，将 `kind` 设为 `"assumed_wall_thickness"`，用同一段墙两侧的 `wall_face` 控制。填写假定毫米数、图上对应位置和判断理由。在交付说明标为暂定，待实测。两种无标入口均生成毫米图，印刷尺寸数为零。不要把面积数字、家具图例或房间名称当作实测跨度。

## 编辑 scene.json

[可运行的小例子](../examples/dimension-grid.json)包含墙中、墙面、洞端、柱边和反向链。它使用合成图坐标。把脚本与该例子同放在技能包中即可复查。

```sh
python scripts/build_observed_structure.py examples/dimension-grid.json /tmp/grid-example.dxf /tmp/grid-ledger.json
```

- `dimension_grid.controls` 以自选 ID 为键。每项填 `axis`（`x` 或 `y`）、`px`（统一刻线像素，最多两位小数）、`kind`、`evidence`。构件控制还须填 `bindings`。只有方向和位置可判读时填 `datum`，注明依据，保留独立尺寸界线。
- `wall_center` 绑定 `{"wall":"墙ID","at":"center"}`。`wall_face` 绑定同一墙的 `min_face` 或 `max_face`。两侧按 **CAD 世界坐标** 区分，须先单独判断墙厚。定义点在墙面时，建模入口自行加减半墙厚得到墙中。
- `opening_end` 绑定 `{"opening":"洞ID","at":"a"}` 或 `b`，次序沿用原图观察。对应尺寸从同一实际洞端起算，开启扇及扣洞使用同一端点。`column_edge` 绑定已建为矩形实材的柱边，可用 `min_face`、`max_face`。用墙条纵向端面代表柱边时，对应的 `cap_a_mm` 或 `cap_b_mm` 明设为 0。
- 每条尺寸链填 `id`、`axis`、`controls`、`values_mm`、`witness_px`、`line_px`。后两项是垂直于量测方向的像素坐标。已绑定构件的标注定义点优先落在实际构件上；独立控制线使用见证位置。阅读方向可正可反，`values_mm` 始终填原图的正数。可选的 `start_mm` 始终按实际世界坐标填写，图上自上向下的 Y 链在 CAD 中逐段减小。
- 如果上下两行读到的同一末端有 1 像素差，先确认它们确实是同一控制，选定统一 `px`。各链另填原始 `ticks_px`，`dimension_grid.tick_uncertainty_px` 只采用本图可读的误差。原始值和偏差进入登记。毫米闭合冲突、反折或无依据的跨链起点会中止建模。
- 用 `source_to_mm` 作为已有图纸的工作坐标基准。没有已有基准时可省略。可在 `dimension_grid` 填 `origin_px`、`origin_mm`。未给出的原点默认为零。一条连通链已给 `start_mm` 时按其世界坐标定位。

## 出图和复开

共同建模入口会把原始观察投到工作坐标。按刻线分段内插，两头按同方向控制点的平均斜率外推。未标注的局部坐标仍是推定值。V1.3用墙两侧原像素及对应方向的局部分段比例，从240、200、120、100毫米中合理选值；明确墙厚标数优先。成品家具尺寸保留输入毫米数。同步换算墙端、洞口、房间净区、家具落点和朝向。已有毫米坐标仍须核固定面及版本，不能重复偏移。由同一墙面控制导致的墙中偏移，会传给原图相交的墙端和这条墙上的门窗。

从 DWG 复开副本，看尺寸的实际定义点、实量及对应墙面或净洞。可另外在副本移动尺寸定义点再生，核对文字随实量更新。定义点随尺寸编辑更新，不能据此宣称移动墙后标注会自动关联。关尺寸层，仍应能从实际墙材和洞口量出同一跨度。原图上没有对应墙的独立尺寸界线，在登记中保持 `datum`。

每项保留源ID、原标数或派生依据、定义点值、实际构件两端及句柄、取面候选和判断。墙位须用源图与成品的同一截面复量；名义墙中和重叠墙的实体并集中面分开。尺寸数字相同但墙面、边界身份或敞口不同，仍记需返修。源图像素误差只用于未标面的估读范围，不放宽清楚标数，也不作为贴合或施工容差。实例数量由本图独立清单决定。

`registration.json` 中 `source_to_mm` 表示工作基准。新图的原图映射还需要 `grid_registration.axes`。叠图使用 `GridProjection(registration).source_path(毫米折线)` 回到原图，独立原图测线用 `world_path(原像素折线)` 进入 CAD。跨刻线时在分段位置插点。原图观察、原始像素及验证点保持可复查。旧作业缺少 `dimension_grid` 时保留原入口行为；新绘任务优先使用上述三种入口。

分段函数使用 [ZWD11/house-plan-designer 固定版本中的 axismap.py](https://github.com/ZWD11/house-plan-designer/blob/d4e7374896e3283883e88d1bcef356eccd320926/scripts/axismap.py)。随包保留[原始代码](../scripts/vendor/house_plan_designer/axismap.py)和 [MIT 许可证](../scripts/vendor/house_plan_designer/LICENSE)。建模关闭上游默认的 10 mm 取整，以保持原始毫米数。登记中的 `intervals` 会列出每段毫米/像素及所用的外推斜率。超过 15 像素的区间与该轴平均比例相差 3% 以上时提示复核读数。

### 龙汐山 132 ㎡的四链独立复算

2026 年 11 月 11 日的执行记录保留了 `check_axes.py` 的初版、末次修改和四链输出。随包的[龙汐山四链复算示例](../examples/longxishan132_axis_check.py)恢复了当时使用的刻线约位、采样带、灰度权重、取整精度和计算式，增加了原图哈希检查与命令行入口。可从正式项目的复做 ZIP 直接读取原图，不修改 ZIP。

```sh
python examples/longxishan132_axis_check.py "/项目目录/本案复做包.zip"
```

每条尺寸链单独用自己的首、末刻线和印刷总长拟合一条直线。把各中间刻线像素代入直线，再减去该刻线的累计印数。按上、下、左、右四条链取最大绝对差，分别为 **6.94、23.59、38.01、7.83 mm**。左链在原图 y = 532.109 px 处累计标注 10500 mm，首末直线预测 10538.01 mm。这就是当时所说的“约 38 mm”。

将右链的分段函数用于左链同一刻线时，得到 10545.44 mm，跨链差为 **+45.44 mm**。程序另外报告各链用自身刻线分段后的复算残差。上游 `Axis` 在内部把输入刻线保留到 0.01 px，而本次从图上提取到 0.001 px，因此同链复算也有小数残差，四链最大约 0.173 mm。以上均为印刷刻线位置与累计印数的比较；墙中、墙面和门窗端的位置另按图面确认。重新手选像素、换扫描带或使用另一版图片，读数可能不同。
