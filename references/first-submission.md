# 从原图观察表生成首稿

本页提供结构建模细节。历史盲测的冻结规则仅用于明示的实验。生产首稿执行[绘制、独审、一次修正和交付](working-release.md)。

每个绘图者自己看图。把时间用于辨认墙芯、洞口和家具。正交住宅平面使用共同的生成及核验操作。一个屋子由各条有厚度的墙围出；画房间时只记录净区，不把房间矩形画到墙层。源图中的墙轴、净洞和扇的方向属于绘图者独立输入。

读不清平开扇时，把自己识得的两个洞端交给像素对照工具。横洞用 `--axis h`，竖洞用 `--axis v`。例如 `python scripts/swing_evidence.py 原图.jpg --a 120 240 --b 180 240 --axis h --ratios 1,0.7,0.3 --out 暂存/某洞`。在输出图中比较原图、四种铰侧与开启象限，分别看扇和弧；比例由本洞大小扇的图像证据决定。空白、门槛、遮挡与多解情况留给执行者结合房间通行判断。单根门槛或程序排序不构成开向证据。

1. 分区放大原始图片，先在遮挡少的位置取深、浅墙芯样点。沿每条水平或竖直墙提取候选色带，核对是否是墙、柜边、门槛或外缘，再决定起止和层。可用[墙芯扫描与墙材操作](wall-tools.md)。按房间行走，分别标出从室内到门前、门洞到另一室、窗端左右的材料。留两份对照：原图局部、自己的墙/洞编号。不要只看一张漂亮叠图就交付。
2. 在 `scene.json` 中写原图像素位置。参考[可运行的虚构小样](demo-structure.json)。`source_to_mm=[a,0,0,e,tx,ty]`，a 为正、e 为负，原图左上角为像素原点；宽度、厚度、扇厚、净距仍用毫米。墙的 a、b 为中心轴端点，material 为 bearing 或 partition。先登记完整母墙，凿洞段包含在母墙轴内。墙芯换色时另起一段，可把横跨多段的洞与那些宿主关联。墙端接至同一轴心交点；短垛或明确止于墙面，按原图声明端面。弧墙、斜墙按图例另建，沿用同一组检查。
3. 每个可见门、窗或通行开口独立一条记录，共用 `id, hosts, a, b, kind`。a、b 是同一条墙轴上的两个净洞端。平开门须为每扇指明铰在 a 或 b、占洞宽比例和开向房间内的一个 `toward` 点。这样横门、竖门和镜像布局都以真实房间决定开向。子母门写两扇并分别看原图大小，不能按洞各占一半代替读图。无证据时不要随便指定一个统一开启方向。已读到可见扇长可给 `radius_mm`，保留图符推断。推拉门依据原图填写 `tracks_mm` 及 `panels`，每扇各有起止比例、所在轨与可辨箭头；图源不清时不加箭头。窗用 `lines_mm` 画在本洞内，不能拿邻窗替代另一洞里的推拉扇。
4. 写各房间可确认无墙的地面样点或小面。自由点要覆盖实际过道、灶台前、床侧、卫浴使用空间及相邻门间；墙体闭合和开洞后仍需检查。重要实墙连续段用 `proof_line` 登记轴上应有材料的线，避开已知窗洞。尺寸链使用标数逐段累加；不连续标注分成两组。黑灰被门槛底纹连起来时，若门弧、框端和实际通行关系支持开口，应把门洞扣透。
5. 使用下面的公共入口生成结构 DXF 和模型毫米坐标的检查表；在返回的同一个 doc 内布置家具后保存。默认把已确认的开口从实际墙材扣除，并**从同一条记录生成对应的门窗实体**。如果因错宿主或断端报错，回到源图和观察表，核实宿主和共用轴端。不得用取消错误、少画一扇门或删除真实墙材来取得通过。对通长栏边及接邻框的边界可按图注明，不造墙垛。

```sh
python scripts/build_observed_structure.py scene.json 结构.dxf checks-mm.json
python scripts/check_room_material.py 结构.dxf checks-mm.json
```

在 Python 中也可调用 `doc, ledger = create_structure(scene)`，继续在 `doc.modelspace()` 插入库块、台面和定制柜，再保存。毫米清单与返回的 doc 配套。每次更改观察表都重新生成，并从交付 DWG 复开后再运行检查。尺寸用实际 CAD 定义点和新文字交叉验证。

无实体宿主的连续栏杆、开放边框或玻璃隔断，若从图示确能判定是自由边，在相应记录中写 `hosts: []`、`free_frame_reason` 和 `symbol_depth_mm`，保留其图符并核净区。不要为了凑宿主而生成整条实体围墙。明显四边闭合的房间外框也不能单独作为实墙填充。

每个通行门用 `connects:["房间一","房间二"]` 说明实际连通关系。住宅入口一侧写 `outside`。厨房、内卫、套间和阳台逐个从入口试走；真正开放且没有门洞的两个生活区域可用 `open_room_links:[{"rooms":["客厅","餐厅"],"evidence":"同地面连续区域"}]` 表达。封闭竖井和纯设备空腔可写 `accessible:false`。平开门除直接给 `toward` 点外，也可用 `opens_into:"房间名"` 采用该房间读出的第一个净空点。淋浴屏等不连通两个房间的隔断可标 `fixture_partition:true`。程序检查登记的房间是否全部可达，实际门洞和箭头仍要在回读图中核对。

6. 家具先从原图逐件列数和使用朝向，再按照完整尺寸与动作布置。靠墙的实物边在放置时直接吸附；有意留开时记录原因。要缩小某件家具才能避免撞壁时，先检查朝向、原图遮挡、是否误套轴和墙位，再选一种仍能正常使用的尺寸。禁止将一组椅子当成一整个桌块，也不能把桌面遮住的椅身裁掉。两边座位须朝相应桌边，拉出后椅身完整，桌的遮罩随桌移动。
7. 首次交付前，自己从保存的候选出具：真实墙材/不应有墙的净区和门窗实物核对；按房间逐件家具尺寸与摆向表；动态尺寸和图层切换；有固定结构的凹槽、粗细墙段与短垛的同底局部。读出自己的文件，修正确定错误后再提交。**已经宣告提交的文件即冻结**。缺项作为本轮成品的真实缺陷；不能通过宣布下次会做、换个文件名或移交审图者完成来获得本轮通过。

从原生回读文件生成两种图。在纯 CAD 图里检查没有被底图“补齐”的缺件，在叠图里检查定位与朝向。此工具显示分类几何，不代替原生打印、遮罩显示或CAD开关层检查。

```sh
python scripts/render_source_overlay.py 原图.jpg 本轮原生回读/readback.dxf registration.json 原图叠图.png --plain 纯CAD线图.png
```

## 多轮首稿验证

每轮用全新执行上下文和同一版工具；保留独立首稿、摘要、使用范围和本轮证据。盲审不回传给本轮绘图者。若未达到事先明确的可用线，将失败概括为可迁移的读图方法、生成工具或回读检查，更新 Skill，再用新执行者从空白提交。下一轮的输入不能包含上一轮房间坐标、标准答案、图纸、局部纠错提示或审图者测区；目标是验证技能的首次绘制能力。对某户型多轮开发后的结果，与换到另一个首次遇见的户型的结果分别报告。
