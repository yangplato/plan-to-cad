# 两次独立读原图，再生成一份首稿

先由一名读图者只看原图独立读一遍。再由绘图者只看原图读一遍。两份记录完成之前互不展示。每组都从原图开始。读图者可使用原图裁片、墙芯色采样和原图数字化工具。独立读图者不绘制待交图纸，也不看工作模型、标准答案或历史案例。在跨模型测试中，两人使用同一种模型和推理档，三组的读图记录分别生成，互不交换。记录使用者的角色、输入图校验值和每步结束时间。

## 读图者要交给绘图者的内容

用本图像素登记整圈外缘和每个房间的周边。每条边依次写出连续实墙、门垛、窗、敞口、移门与栏边，包含每一处交界；向前走一遍，再从另一侧反向核对。彩图上深浅材料取未被纹理或水印遮盖的墙芯样点。在图上标出实际可见的代表色、连续轴段和每一道受控制的开口。原图上有弧的平开门，看清洞两端、开向哪一侧、活动扇的铰点和远端。可见弧时描首端、中部、末端的三个以上像素点，与从铰到开的扇端直线互校。示意较难读时把相邻地面、门垛及两个候选都写下。

必须保留原图的真实像素坐标。每个可见的门、窗、玻璃、栏杆或自由边在 `portals` 登记一次。见不到明确门扇的通口可填 open。输出 `source-reading.json`。以下是虚构例子。

```json
{"source_sha256":"实际输入图的校验值",
 "portals":[{"id":"入口","kind":"swing","a":[30,20],"b":[55,20],
 "leaves":[{"hinge":[32,22],"tip":[32,45]}],"between":["室外","玄关"],"basis":"可见开启扇边及弧"}],
 "regions":[{"id":"玄关","box":[20,15,80,95]}],
 "marks":[{"id":"入口中央过墙","kind":"clear","line":[[43,13],[43,27]]}]}
```

`kind` 可选 swing/sliding/window/rail/open。非平开项 leaves 为空列表。为每扇填入从原图点取的 hinge、tip；每个开口取三个穿墙探线。为明确的分色实线和家具真实位置，按[原图标记格式](source-first.md)写入 marks。家具另存逐房清单，明确类别、部件、件数、朝向、贴墙背边、支承关系和推断。根据图上户型本身识别数量。不得在室内把所有腰线都当门槛，也不能掩盖有清楚图证的缺件。两轴根据明标尺寸独立校准。另给机器可读的墙轴/色段、现场使用拓扑及尺寸链，使绘图者可从观测复现而不需要重新猜测坐标。

## 让两份记录发生作用

绘图者保存自己的源图记录后，再打开同组读图者的记录。按本图实测像素模糊带匹配洞口并排显示原图。两次读图的门洞端点、宿主方向、种类、铰侧、房间去向或件数不同时，必须回到原图定位。输出一份解答，保留两个原判断、取舍与图面依据；两人同意的判断仍可能有共同错误。两份登记中的所有屋内入口均需在实际 DWG 回读上核通行。

```sh
python scripts/compare_source_readers.py 原图.jpg 自读/source-reading.json 同组仅读原图/source-reading.json 差异 --band-px 本图读差
python scripts/fit_swing_trace.py 原图.jpg 弧形点列.json 门弧核查
python scripts/recheck_source_marks.py 回读/readback.dxf registration.json 同组仅读原图/source-reading.json 外部原图探线
python scripts/survey_against_model.py 原图.jpg 普查/source-survey.json 回读/readback.dxf registration.json 像素冲突 --tone dark=bearing
```

弧形点列为 `[{"id":"门1","arc_px":[[60,30],[56,42],[45,50]],"open_tip_px":[45,50],"uncertainty_px":2}]`，数字须换为本图读数。arc_px 按从关闭端经过弧的中部到打开端的顺序取。弧不清不强行拟合；记录可以辨认的部分并在原图局部核对。墙芯专色和深浅所代表的墙类需按项目图例核对。程序不会把所有深色家具认作结构。

建图前从上述两份原图记录生成同一份结构观察。用[按母墙色带定位墙段](color-guides.md)保留真实色段和透空。用[设备功能符号](fixture-families.md)表达固定设备。工作模型中发现任何门后仍有实墙，必须查看源图并逐端核本洞，不得移动探线以通过检查。尺寸、家具几何、门与柜的扫掠及图层开关按原流程执行。外部盲评只接收最终的一份首稿。

在原生回读中检查整屋物件的实体占地。对柜和床、同一组座椅与小几、桌前和窗前的支持边做局部实量。可批量列出全部家具之间的投影、门扇扫掠与墙交叠。对有意的上下叠放，逐对填写两件的实际 CAD 句柄和理由，盆槽另填台面宿主句柄。桌下收椅、嵌入盆槽、床边硬碰家具要分别核实。有框线无法还原轮廓时用原图和实际实体边补测。

```sh
python scripts/screen_furniture_pairs.py 回读/readback.dxf checks-mm.json registration.json 家具交叠.json --relations 有意叠放.json
```

有意叠放文件为数组；每项如 `{"handles":["12A","14B"],"host":"12A","basis":"盆属于此台面，查完整安装轮廓"}`。没有登记关系时省略该参数。每个输出的未解释正面积都回到纯 CAD 和原图核实。对桌椅重点看实际座面和移动方向，不能只以外接矩形判碰撞。

## 合在一次运行的首稿自检

```sh
python scripts/preflight_first.py 原图.jpg 候选.dxf registration.json checks-mm.json 自读/source-reading.json 新自检目录 --reader 独立读图/source-reading.json --survey 原图普查/source-survey.json --relations 有意叠放.json
```

同一命令串行在临时副本保存并复开、切换两种家具层、实改标注、实测原图探线、输出逐房对照图和家具扫掠表。输出 `summary.json` 可直接定位仍需判断的对象。重画后选新目录，防止读到上一份检查。无独立读图者的普通出图可省略 --reader。没有有意叠放清单时省略 --relations。只有原图有足够标注时才能判断绝对毫米尺寸；查明显尺寸能否更新还须核对原图端点与实际墙面关系。
