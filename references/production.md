# 由读图到 CAD 的共同做法

此页说明单项几何做法。新作业默认以[命名控制点](dimension-grid.md)配准，以[逐边登记](object-edges.md)放家具，按[集中修正](working-release.md)交付。

## 开工时留下的依据

在已有作图记录中按房间从入口顺时针走一圈。用同一个编号连接原图位置、模型构件和读回结果。只记本案需要的对象，局部任务明确范围。记录三类事实：

| 对象 | 建模前从图上登记 | 完成后回到 CAD 量 |
|---|---|---|
| 印刷尺寸 | 两端刻线的原图坐标、标数、横纵方向、对应墙面/墙心/控制线，分开的尺寸链保留空档 | 在相应位置找到一个原生尺寸，读取定义点、实量和显示规则；抽动副本定义点确认数字跟随 |
| 墙和洞口 | 每段连续外墙和内墙的两面。每个洞的位置、宿主、两端的墙垛或邻框、类型、几扇、铰点、朝哪边开；圆角或通长窗按实际端接登记 | 从最终墙材量洞腹和全厚，两端有无应有的实材、洞侧的断面；检查门窗线是否到达对应端面，门从哪一间开向哪一间 |
| 家具 | 按房间列可见件数、类别、包围范围、朝向、应贴的实体边和需要留出的使用空间。看不清的小物注明 | 从最终块轮廓量床头、柜背共边；查越墙或有缝，柜、床脚和椅背对通行的影响。对照原图检查种类、数量、层和占地 |

先保存原始像素、两轴换算、同图不同区域的验证点。沿一整段墙读墙芯，在颜色发生变化处分别登记，连同窗头、窗垛、外墙小凸出和截边空间逐个核对。对门口两侧、虚实交界、相邻两扇门或家具旁有争议的边，附小图辨别。若只确定尺寸沿链投影，按该轴验位置。不能从控制线推导它与某段墙存在关联。图面模糊度以当前原图原生像素和每像素的毫米数记录。模型中应共边的对象按 CAD 坐标量。两种误差分别处理。

同一条尺寸链从已定位的锚点逐段累加印刷标数，计算 CAD 控制坐标。像素换算用于选择和复核相应刻线。对平开门，把铰点、闭合端、全开扇边分别落在原图局部上。核对洞口是否起止于两侧真实门垛。对带水平箭头的门，先辨认移门线和开启方向。截图边缘出现半段相邻房间时，同样核查范围内可见的开口和窗端。

## 共用制图操作

绘图者可以沿用已有 CAD 方法。如果用 Python 生成毫米制 DXF，`scripts/draw_plan_parts.py` 提供两个操作。把该文件所在目录加入 Python 的导入路径。依赖为 `ezdxf` 和 `shapely`。

```python
import ezdxf
from shapely.geometry import box
from draw_plan_parts import add_mm_dimension, add_wall_material

doc = ezdxf.new("R2018", setup=True)
doc.units = 4
msp = doc.modelspace()
for layer in ("承重墙", "构造墙", "尺寸"):
    doc.layers.new(layer)

# 示例为一段直墙。坐标由每张图的尺寸和轴线决定。
walls = {"墙一": ("构造墙", box(0, 0, 3200, 120))}
openings = {"门一": (["墙一"], box(400, -1, 1300, 121))}
add_wall_material(msp, walls, openings, {"承重墙": 54, "构造墙": 186})
add_mm_dimension(msp, (0, 0), (3200, 0), (0, -450), angle=0)
```

- 将本轮全部墙段一次传入。从同一份扣洞后的几何生成墙边线和填充。墙类交接处按项目确认的材料优先顺序去除重复面积。输入中的开洞多边形要贯穿本段全厚。按真实宿主指定开洞。若另一段墙仍占据该区域，处理连接关系后重新生成。
- 以上操作适用于直边墙。要保留真圆弧时，使用能保留圆弧的原生 CAD 实体；对交付文件用同样的洞口和端接判据。门的铰点和开向、窗线、正反侧及家具选位均由绘图者从原图判断。空白的墙洞只是第一步。
- 将门框、门扇和玻璃定位到真实墙端。给一条直窗画框时，同时检查另一端。连续玻璃转角若接邻框，按图例验框接框。不要在通长玻璃上补造墙垛。
- 图上可见门扇自由端与净洞宽度可能不一致。分别记录墙口、门轴和可见扇长。按图例表达推定的开启弧，说明其依据。只有门套有原图或选定图例支持时才补相应构件。门垛颜色与相邻长墙不同的，在墙端拆分图层。
- 逐条用原生尺寸对象标注相应控制线，保留动态实量显示。把图库俯视块以自身可识别的角点、中心或靠墙边为基点，在模型中以真实毫米尺寸插入。先读库中块的几何和尺寸，再选型。缺乏匹配块时，可依据图像占地和构造自绘，记下理由。关家具层时，电梯、墙和门窗应保留。

## 发给独立审图者

首稿自检先完成[墙芯、移门和家具组读图](read-walls-and-sliders.md)及[全户家具尺度判断](furniture-reasoning.md)。图块若带遮罩，另在副本只移动遮罩所属的桌或柜，检查遮罩线随行且椅子保持原位。定制尺寸样式要绑定图中存在的文字样式，用后台 CAD 修改尺寸定义点并读出重生成的实际文字。初始标数正确仍须做这个编辑检查。

绘图者自己先改到各项自查有结果，再锁定候选版本。图面包含门窗及房间关系的整户交付、跨模型对照、或有明确读图争议时，安排与绘图者分开的审图者。尺寸文字调整等已有独审底稿上的小修，复测涉及对象与相邻部位即可。

给审图者：原图与方向、任务范围、用户图例和可用资料、匿名冻结文件、交付单位与常规图层对应。先独立列出可见洞口、墙段和主要家具，也可在绘图时并行读原图。让审图者按同一配准自己生成叠图或从最终文件量测。完成第一轮判断后，才调阅作者自述、推断表及可选的同户型人工图。多模型比较时最后揭示模型及历史分数。审图者可以选与作者相同的模型，但应使用独立上下文。

审图者交回位置或编号、图片依据、CAD 实量或图像、影响和处理状态。常规修图时由绘图者修改几何来源并重新生成，审图者再从新文件复核。若委托为首稿盲测，保存结论并结束；评审期间不得回传问题让绘图者修改候选。没有独立代理时，可交付已有证据并标“已自检，待独立复核”。有同户型人工 DWG 与有独立审图者是两个不同条件。
