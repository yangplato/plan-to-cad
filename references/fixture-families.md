# 厨卫设备、转角柜和建筑附属

从营销图先读每件实物的外边、使用侧及相邻墙面。台面、水槽、灶具分别量取。转角柜按实物的 L 形占地计。对模糊的局部，登记可见轮廓及推断依据。选用项目图库中形态相符的俯视块，或使用下列已有图形。

| 放置名 | 尺寸、方向和图形 |
|---|---|
| `sink` 水槽 | 宽、深量槽沿的外包尺寸。以靠排水口一侧的槽沿为后边。直接复用已核过的单槽 `sink_inset`。双槽另选匹配块。 |
| `hob` 灶具 | 宽、深量灶面。前向指向操作侧。以 `burners` 指定实际可辨的 2 或 4 个炉头，嵌入式画面板和炉圈。认出带机身的四区一体电炉时，可给 `electric_range: true` 选用通用 E19 四区电炉实物块。 |
| `washer` 洗衣机 | 宽、深量单机外包。前向指向操作侧。`washer_loading: "front"` 为前开门单机俯视，正面留拉手边。`"top"` 为带顶盖的单机。前开门是缺省形态，型号不清时在观察表中注明。另留开门、取衣及进出通道。 |
| `shower_screen` 固定淋浴屏 | 用一段窄矩形画固定玻璃。宽度取两端之间的屏长，进深取屏体厚度，前向由一条长边指向另一条。逐段画实际可辨的转折，入口处留开口。活动屏另据开启方式表达。 |
| `basin` 台盆 | 宽、深量盆沿。前向由龙头安装侧指向使用者。通用 E19 台盆保留盆沿、盆腔和孔位。台面按本案轮廓另画。 |
| `x_frame` 建筑附属 X 框 | 量实框的矩形外包，画一框、两条对角线。原图只见叉线而用途不明时，记录为“建筑附属 X 框，用途待定”。归入建筑附属层，可独立关闭。 |
| `corner_wardrobe` 转角衣柜 | 宽、深为整个 L 形的外包。另给靠后墙一翼的进深 `back_depth_mm`、沿侧墙一翼的进深 `return_depth_mm`。从使用侧面向后墙，`return_side` 的 `left` 为左手边有侧翼，`right` 为右手边。检查两翼贴各自墙面和内凹角的可用空间。 |

`back_mm` 是后边外包线中点的 CAD 毫米坐标。`facing` 是从后边指向前边的 CAD 向量。例如 `[0,-1]` 朝图下，`[1,0]` 朝图右。宽沿后边测量，深沿前向测量。灶具和水槽以各自后边定位，后边和厨房墙面之间可以有一段台面。柜后边采用房间侧的墙实面。屏体的 `back_mm` 取所选长边中点，避免重复算半个厚度。

## 放进正在绘制的 DXF

将每件的信息写入 JSON 列表。以下两项只演示输入方式，坐标和尺寸均为合成数据。

```json
[
  {"id":"厨灶","family":"hob","back_mm":[2100,3600],"facing":[0,-1],
   "width_mm":730,"depth_mm":410,"burners":2},
  {"id":"卧柜","family":"corner_wardrobe","back_mm":[4200,6100],"facing":[1,0],
   "width_mm":1800,"depth_mm":1250,"back_depth_mm":570,"return_depth_mm":550,"return_side":"left"}
]
```

```sh
python scripts/place_plan_fixtures.py 本案设备.json --drawing 已建整图.dxf --write-new 带设备整图.dxf
```

省略 `--drawing` 会生成便于核对的独立样图。输出文件须使用新的文件名。工具逐件返回句柄、块名和图层。水槽直接取 Skill 内的嵌入式单槽。通用 E19 库中的前开门洗衣机、台盆、四区一体电炉分别取 `E19-058-03`、`E19-016-02`、`E19-081-02`，均已按真实俯视图核对。前开滚筒在机身正面，俯视图显示机顶和门把手的外缘。

从[室内平面图块库](plan-families.md)选厨卫设备时，使用对象表的 `library` 类型。使用本文的 `fixture` 类型时，可通过 `--library 通用E19.dxf` 或 `MPCAD_FIXTURE_LIBRARY` 指定获准使用的 E19 库。提供 DWG 格式时需要 `dwg2dxf`。未指定 E19 库时，此工具使用内置功能图形。使用 `--simple` 可直接选这套简图。块名中的 E19 编号、`SCHEM` 和 `SINK_INSET` 分别标出通用库、简图和内置单槽。图库曲线转为可编辑多段线，按实测宽、深放置。完整参数也可从现有脚本调用。

```python
from place_plan_fixtures import place_fixture

ref = place_fixture(msp, "shower_screen", back_mm=screen_edge_midpoint,
                    facing=across_glass, width_mm=screen_length, depth_mm=glass_thickness)
```

顶层块参照默认落在“固定家具及设备”或“建筑附属”。项目另有层名时，逐件用 `layer` 对应业务大类。块内图元均在 0 层。调换后边、转角方向或尺寸后，观察外包及实物边，复核台面开孔、门扇和走道。审图时从存盘复开的 DWG 实际关闭固定设备层和附属层，分别查看对象隐藏与保留，按[关层回读方法](acceptance.md)记录用例。
