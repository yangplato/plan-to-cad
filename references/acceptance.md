# 统一判定与回读

普通生产由一位绘图者和一位独立审图者完成。判定针对当前户型实际构件。范围外项目记不适用。人工计时、纸面试印和本轮停止条件见[首稿交付](working-release.md)。

先固定委托范围。按原营销图独立清点对象，各类记录“应查／已验／失败／待核”。同一户型、同一范围用同一清单和容差。所有关键项都有位置、对象和回读结果后，才能判整图通过。未画的原图物件也计入清单。每次修订关联候选文件名与摘要值，刷新失效的结果。

本版把准确性和纸面表达均作为交付门槛。标数、定义点、实际实体、空间净距及构件身份分别判定，不互相代替。源图未给工程轴网，不把重建控制线称为工程轴。覆盖数量由本图独立枚举，不套用历史案件固定条数。缺边界、原生复开失败、打印信息缺失或尚未看实际PDF，均不能写整图通过。

## 判定表

| 类别 | 通过的条件 | 常见漏判与处理 |
|---|---|---|
| 输入、定标及标注 | 原图版本明确，已标尺寸能一一对应原生、可编辑、动态显示的标注。尺寸实量在该标注的显示精度内，并落在对应控制线或定义点。分开记录几何实量、标数和动态显示。 | 直线加文字、写死的数字、选择另一处同值尺寸冒充本段都须返修。有可见刻线但墙面无对应时，可保留独立控制标注。额外推定尺寸须标明。 |
| 墙与房间 | 原图中每个房间能从正确入口到达，开放区连通；外墙、相邻墙芯和短墙垛存在于正确区间，轮廓与填充一致，无非设计缝和重复实材。 | 画出了门弧仍要查门后是否有墙。查原图所有连续墙段，不能用一个角点推定整条外墙连续。原图没给结构性质时另列待核。 |
| 每个门、窗和端部 | 同时满足三件事：洞腹清空至全墙厚，两端对应墙垛或邻框真实存在并与框端接合，门窗类型、扇数、铰点和开向符合可见线索。检查案内所有可辨开口；窗框范围、洞内净区与端部搭接分别量。 | 图形对上窗端的横坐标，仍须查同一高度有没有墙垛。角窗、端窗、敞口按实际节点核对，不强制两端都有墙。可解释的框内搭接与穿进净洞的墙材分开。 |
| 家具与使用 | 来源与占地可追；床头、柜背等应贴边有有效共边；应留空的通行、开门、拉椅和安装位置可用。逐房间比数量、朝向、主要轮廓和落点。 | 核对窗边小几是否被识成椅，把保留的设备、厨房操作台和固定柜逐件定位。真实侵墙、妨碍通行、明显错类漏件或超出读图带且改变布局的占地偏差须返修。像素范围内且不影响使用的样式近似可记录。 |
| 分层、复开 | 交付文件能后台复开。关活动层时活动家具消失，固定柜和建筑附属仍在；关固定层时活动家具仍在；双关后建筑附属、墙、门窗等继续可见。用原图清单在独立位置抽取这几类代表，再核对图层归属。 | 只统计“两层都关后为零”会漏掉电梯、柜子和沙发同层。块内线归 0 层，块的插入点和旋转中心有实际用途。 |
| 图纸与实际PDF | 图框、图签和图例在真实纸空间，房名在模型空间；实际纸幅、视口及输出比例符合本案设定。尺寸与文字无白色覆盖。各自定义层有实际内容，清单区分空间。线宽、填充、字高、符号和界线留白可读。 | 须实际看整页和正常阅读局部。逐层检查实际实体及关层结果。文件名、模型空间仿图框、页数、页面尺寸或渲染命令成功，都不能单独代替纸面检查。 |

**家具、洁具和固定设备的全户尺度验收。** 图上对位完成后，从最终文件逐件读回。按[家具尺度与使用](furniture-reasoning.md)检查每一件物体的完整宽深、分类和用途，再检查相邻物件能否配合。合理性采用模型学到的常规尺度和空间使用知识，无须检索厂家数据。遮挡线、整组外包、桌椅收拢净距分别量。记录实量、经验判断与依据、实例数和异常处理。发现半把餐椅、马桶比例失真、挂衣柜明显不足深、水槽悬空或其他会影响使用的异常时，整套家具验收不通过。特殊家具给出图像或用途依据；仅凭“贴图”不能通过。

**误差按来源设定。** 标注按原标数、单位和舍入精度验实量；待查像素位置按原图分辨率、边缘清晰度及独立配准残差取读图带。CAD 中要求贴合的边用几何计算精度核实。给定墙体、洞口和主要家具不按通用像素数、面积比或另一案例的毫米数设定验收线。门扇、设备实际安装净距若只能推定，就写明推断。对每处偏差记录受影响的使用动作。

读图带只描述影像中未标面的辨认能力，不是施工容差，也不适用于清楚的原标数。端面候选不同须并列。尺寸对象可以数值正确而墙体位置或身份错误；敞口可以图符完整而实际净区仍有墙。墙厚检查使用实体并集；空间净距使用实际功能面。缺项如实记待核或需返修，不从自填参数表补值。

V1.3墙厚按240、200、120、100毫米四档合理选择。逐墙核原图两侧像素、当地尺寸比例、候选范围、取值理由、实际厚度及固定面。明确墙厚标数优先；图读范围覆盖多档时保留候选，并查控制面、相邻净距或同类清楚截面。不得仅按深浅墙类强制取240／120。柱、窗框与栏杆单列。改变墙厚后，复量控制线、门洞、相邻净距及应贴墙家具；图读推定不称现场实测。

**状态。** 查实上述结构、可编辑、归类或使用缺陷，标“需返修”，列出可保留部分。关键项未测或文件无法可靠解码，标“待核”，可附可编辑底稿。问题同时存在时先列已知失败，再列未核。适用关键项均通过后，可交付，并单列不影响使用的图源推断。用户是否接受另记。评分可用于定位强弱和同状态下排序；不能抵消封洞、漏墙、错误归层等问题。

局部测点全部通过时，先核对本次清单的覆盖范围。审图者在测点外发现的问题也进入同一返工表。修好一个窗端后，沿该段整面墙检查另一端和所有同类窗头。修好一扇门后，沿实际行走路线检查相邻门、另一种门型及相邻墙体。独立审图需列“已复测关闭”和“仍待处理”的编号。

## 从文件取证

使用共同生成入口时，把结构导出的毫米检查表保存为 `checks-mm.json`。整户家具布置完成并后台复开后，运行 `python scripts/first_readback.py 本轮原生回读 checks-mm.json 本轮自检 --layers 活动家具 "固定家具及设备"`。它从实际保存的文件检查室内误填、净洞残材、已注册图符存在、动态尺寸、家具块与占地提取。它只能核查绘图者已登记的对象。最后应以全屋原图逐区清点遗漏及真正贴靠的背边，并对椅子、坐便器、柜体等逐件写用途判断。生成库块与对位见[库块和真实墙面放置方法](place-and-check.md)。

用带 `ezdxf`、`shapely` 的 Python。在 Skill 目录中运行。将 `读回.dxf` 换成交付 DWG 后台复开后导出的文件。仅交付 DXF 时，直接重读已保存的 DXF，并记录验证层级。

```sh
python scripts/check_wall_probes.py 读回.dxf 墙洞预期.json 墙层与坐标.json
python scripts/check_dimensions.py 读回.dxf 已标尺寸.json --frame 尺寸坐标.json --require-dynamic
python scripts/check_furniture_layers.py 读回.dxf --layers "活动家具" "固定家具及设备"
```

墙洞和尺寸的预期由原图标数、刻线和肉眼可辨的几何确定。先留取预期，再检查 CAD。按原图编号逐个登记；机器脚本只检查传入的对象。可用等效的原生 CAD 截面或量测证据覆盖脚本未支持的曲线、复杂块和填充。若没有可独立验证的定位点，写明配准限制。对照当前实际范围，有家具才执行家具分层检查。

源图几何复核规格写`review_version:"source-geometry/1"`，先从原图独立列本图适用关键项。每个`required_id`须有计算结果及原图、回读、DWG身份；实际值由成品实体计算，不能手填actual代替。独审记录顶层的`source_geometry_review`可承载该规格；严格模式缺规格、覆盖、哈希或有候选歧义时记待核。字段实例见[几何回归小样](../tests/test_source_geometry_review.py)。独立执行入口如下。它的“通过”只覆盖已声明检查，不能替代独立读图、开口全清点或纸面检查。

```sh
python scripts/source_geometry_review.py 读回.dxf 源图几何预期.json --source 原图.jpg --dwg 终稿.dwg --report 源图几何结果.json
```

分开记录DXF重读、DWG解析器回读、AutoCAD原生复开和界面编辑试验。转换后核尺寸方向、定义点、块变换、填充、图层及文字。错误日志未关闭或原生复开失败，先列需返修，再列未查；不能靠数量相同放行。同版DWG、回读及原图哈希一致时复用已有回读；任一文件变化后，相关检查必须更新。

- **墙材。** 独立清单含图源标识和多个检查区域。用贯穿墙厚且避开窗框端部的面查洞内，用两端墙芯及连续外墙的面查实材。宽窗、转折或有交点的长墙按变化分段取区，并检查区段之间的连续性。另沿窗轴实量窗框端面至实填墙的距离。检测区的墙材覆盖量不能替代整窗洞宽或原图全覆盖率。
- **尺寸。** 用每段的起止点、方向和标数作一一配对。仅确定沿轴位置时用 `station`，有明确二维锚点时用 `point`。执行者对仅有固定数字的标注检查副本改点后的实际显示。定位差、缺失、重复、静态文字和几何量值偏差分别汇报。
- **家具。** 分开验证模型空间块的归层、嵌套块图元归层、实物语义和真实关层画面。前两项可用脚本；后两项从原图点名物件，在原生 DWG 的四个显示状态下量测或比对同一视窗。保存一次按家具自身基点移动或旋转的副本测试可识别世界原点假基点。

在配有 AutoCAD Core Console 的 Mac 上，可用下面两步取得同一候选的原生复开与四态证据。选择临时工作目录中的新子目录。程序不使用前台窗口，遇错退出。若安装多个 AutoCAD，通过 `--console` 选用本次可用的程序。只画结构的任务省略 `--layers`，程序只保存和复开。

```sh
python scripts/native_readback.py 候选.dxf 临时工作区/本轮 --layers "活动家具" "固定家具及设备"
python scripts/check_dimension_regeneration.py 临时工作区/本轮
python scripts/check_layer_views.py 语义测区.json 临时工作区/本轮/both_on.dxf 临时工作区/本轮/movable_off.dxf 临时工作区/本轮/fixed_off.dxf 临时工作区/本轮/both_off.dxf
```

输入样例和坐标约定见[最小输入样例](probe-inputs.md)。整户的独立审图路径见[审图者的输入和复查范围](production.md#发给独立审图者)。
