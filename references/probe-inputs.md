# 检查输入示例

用当前项目的原图证据替换示例。以下墙洞和尺寸示例与制图操作中的 3200 mm 直墙对应。源图像素原点设在左上角。不存在的图层省略，不擅自将某层填充原样当作户型实墙。

**墙洞预期.json** 使用原图像素。下例的整个洞内检查区沿墙厚方向超出两侧墙面。为墙垛挑选能确认是墙芯的区域。再用 CAD 中的框端和墙端实际坐标查共边。

```json
{"source":"示例原图-v1","probes":[
  {"id":"门一洞腹","kind":"clear","polygon":[[41,106],[129,106],[129,122],[41,122]],"supports":["左垛","右垛"]},
  {"id":"左垛","kind":"solid","polygon":[[32,110],[38,110],[38,118],[32,118]]},
  {"id":"右垛","kind":"solid","polygon":[[132,110],[138,110],[138,118],[132,118]]}
]}
```

**墙层与坐标.json** 指定所有墙材层、已确认的非墙填充层（可为空），以及原始图片到模型毫米坐标的变换。`source_to_mm` 为 `[a,b,d,e,tx,ty]`，即 `X=a*u+b*v+tx, Y=d*u+e*v+ty`。登记未参与拟合的可确认控制点。容差来自本次图像的读图带。

```json
{"source":"示例原图-v1","wall_layers":{"构造墙":"fills"},"source_to_mm":[10,0,0,-10,0,1200],
 "holdout_limit_mm":10,"holdouts":[{"source_xy":[200,110],"cad_mm":[2000,100]}]}
```

`fills` 读取平面墙填充及其内环。只有已经确认的成对墙皮才使用 `nested_loops`，孤立外框、未知填充用途或不支持的曲线等均留给原生 CAD 实量。若端部接邻框、在图外或无墙垛证据，记录 `unverified_ends` 中的说明并另验端接。打开检查结果先看几何实量和范围，再判是图源不确定、实际漏画或需换一种方法核对。

**已标尺寸.json** 的坐标为参考毫米坐标。两点明确时用 `point`。只有沿刻线方向的投影时用 `station` 并给实际尺寸线的参考位置和读图容差。旋转或更换 CAD 原点时，用 `--frame` 给 `origin_mm`、`x_direction`、`y_direction`。已用同一坐标时可省略该选项。数值差和图像定位差各用自己的容差。

```json
{"unit":"mm","dimensions":[{"id":"墙一长度","mode":"point","axis":[1,0],"p1_mm":[0,0],"p2_mm":[3200,0],
 "value_mm":3200,"value_tolerance_mm":0.5,"endpoint_tolerance_mm":10}]}
```

**语义测区.json** 使用 CAD 毫米坐标。每个矩形只截到待测物件的可见线条，避开隔壁物件、文字、墙线和空白。全开样本先目视确认身份。比较四态后，脚本报告这个矩形内的图形是否如预期消失或保留。模型空间中的整图清点另做。以下坐标单独演示填写方法。

```json
{"unit":"mm","layers":["活动家具","固定家具及设备"],"regions":[
 {"id":"椅背","class":"movable","rect_mm":[100,300,300,450]},
 {"id":"衣柜挂衣杆","class":"fixed","rect_mm":[650,100,900,500]},
 {"id":"电梯轿厢对角线","class":"permanent","rect_mm":[1000,600,1150,750]}
]}
```
