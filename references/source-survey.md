# 从营销原图独立盘点墙、洞口和细线

先读取原始 PNG 或 JPG，只使用原图像素、读出的图幅范围和比例。此步骤适用于首轮读图，也适用于交付前重新核对。工具不读取拟建墙表、门窗表、人工 DWG 或成品 CAD。

```sh
python scripts/survey_source.py original.png --mm-per-px 16 --rect 20 30 820 680 --out survey
```

`16` 是用来演示的毫米/像素值。用本张原图上独立读出的尺寸和像素跨度计算比例。原图 X 向右，Y 向下，图框和房间框均为左、上包含，右、下不包含。线段端点为实际原图像素中心，可有半像素。JPG 的 EXIF 旋转按正常查看照片的方向解释。

图幅不规则时用多边形，坐标间用空格。彩色墙芯、很浅的墙芯可另加取自本图的色样。每种颜色可有独立容差，示例的 15 表示 RGB 空间距离。可选的房间文件只用来补出具名房间原图页。即使房间表漏了一个空间，全图分区仍覆盖该处。

```sh
python scripts/survey_source.py original.jpg --mm-per-px 16 \
  --polygon '20,30 819,30 819,500 710,500 710,679 20,679' \
  --color pale=C8C0B0:15 --rooms rooms.json --tile-px 420 --out survey-detail
```

`rooms.json` 形如 `{"客餐厅":[70,100,440,460],"厨房":[445,100,640,280]}`。省略图框时检查整张图片。输出请选择新目录或空目录。

## 打开结果

1. 打开 `overview.png`，定位蓝色 T 分区、红色 W 墙宽色带、橙色 G 断点和绿色 P 平行线框。总览上标注可能相互遮挡。可用 JSON 坐标及编号定位。
2. 按 T 序号看完全部 `crops-001.png` 等原图页。每格按原图 1:1 像素输出。标题在图外，格间保留 12 像素上下文。多边形的边缘格保留原照片背景。逐格记录房间内四周墙段和材料变化、门窗起止、门轴/扇/弧、阳台边界、滑轨、管井和固定家具。斜墙、短墙、尽端、被遮住的墙线以及没有编号的特征要人工补记。JSON 的 `scope_pixels` 和 `covered_scope_pixels` 可检查核查图是否覆盖选定图幅。图幅本身是否选全需与整张原图比对。
3. 打开 `source-survey.json`。每格 `tiles[].features` 对应位置经过的候选；编号为空的格仍需看原图。`wall_band_candidates` 给出中心位置、起止像素、估算带宽和色调。`long_stable` 表示直线长度和中心稳定度满足门槛。家具边也可能满足门槛。深色及中灰色像素的分类只能描述图面颜色。结构/砌体的材料名称需要图例、两侧墙面和相邻接头支持。
4. 检查 `gap_candidates` 的两端和 `parallel_pairs` 的线条。缺口可能属于门、窗、贴图遮挡或墙体交接。墙芯等宽候选在十字处常会断开。平行线可来自窗、推拉轨、栏杆、尺寸线或家具。逐条看 `manual_conflicts` 的孤立墙宽条、穿过断点的垂直色带、不同颜色重叠区、无墙端夹住的平行线等。对照材料分别记录“采用 / 排除 / 看不清”和依据。双墙面或单边墙线使用按房间原图识读的实际宽度。
5. 当断点约为 550–1300 毫米、有足够像素且四种开向均在图幅内，工具自动比较四组门扇与门弧。状态 `single_supported_tendency` 仅表示当前采样较支持一种画法。`possible_leaf` 的 A/B 对应断点 `a_px`/`b_px`，向量为原图的开向。`inspect_source`、多个结果或范围不足时，保留原图不确定项。双扇和子母门可使用 `swing_evidence.py` 按本图比例另查，并检查相邻门通行。批量普查可传 `--skip-swing` 跳过这个步骤。

默认算法搜索水平、竖直方向约 55–420 毫米宽、至少 500 毫米长的色带，以及约 75 毫米以内、至少 540 毫米长的细线。近邻轴、同色地面、图幅边界、阴影和低分辨率会影响结果。缺少候选不代表原图上没有对应对象。将像素发现作为对照清单的独立来源，再与已画 CAD 逐项比对；工具本身不会生成或补齐 CAD 线。
