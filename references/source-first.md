# 先读图、再建模、最后复看

用同一个执行者分三步完成一份首稿。每一步有自己的输入和结束条件。可在同一上下文内分次操作。外部审图在首次提交并冻结后开始。每轮更改通用方法，再由新上下文用原图复绘。多轮用同一户型时注明它是方法开发案例。

**第一步，只看原图。** 定位建筑范围，放大每个房间，另看外圈一周。从入口出发，沿相邻房间走一遍，再从每个封闭房间向外走一遍。沿周界顺时针另核白框、细平行线、实墙、墙芯变色、开口和边栏。图上窄暗门槛可能横过通路。门槛是否为墙必须结合门扇弧、门垛端及两侧地面判读。在原图上指出每扇的铰点和打开后叶端；子母门分别指出。门扇被图案遮挡时，依照图上能确认的部分和使用逻辑记录推断。边上没有墙芯的栏边要看完整边框，不能直接归入砌墙。结合原图家具类别、方向、数量、完整尺寸、床头靠哪段实墙、柜体转角连续性和动作空间判断。可以先用无标记原图的局部放大，再用[原图线索检索](source-survey.md)找遗漏。若原图标色有色差，用两个原图墙芯样本核验。

本步在生成 CAD 前保存 `observations.json`。坐标始终使用原图像素。保留 `regions` 和 `marks` 两个字段。所有房间及周边独立区域各有局部画框。为每一个可辨开口，在洞宽方向约四分之一、二分之一和四分之三处分别画一条穿透两侧墙面的短线，记为 clear。为每段已知连续深墙或浅墙标一条不含洞口的轴内实线，记为 bearing 或 partition。对每扇平开门单独记打开姿态。家具及设备逐房列出。对象位置选在原图可辨的实体内。不同物件重叠时记录被遮住的部分。同类成组物件仍须能点数。把判读和不确定原因写进对应记录。结构和家具不以固定件数凑齐。

以下各行是虚构数据的格式示例。房间、坐标、标宽、容差及方向均须取自本张原图。门扇的 uncertainty_px 来自原图本地描线模糊带，不能事后放大以通过。

```json
{"regions":[{"id":"例房","box":[15,18,160,180]}],
 "marks":[{"id":"D-1中","kind":"clear","line":[[48,38],[48,49]]},
          {"id":"W-1芯","kind":"bearing","line":[[20,43],[31,43]]},
          {"id":"D-1扇","kind":"leaf","hinge":[32,41],"tip":[32,74],"uncertainty_px":3},
          {"id":"床-1","kind":"object","point":[65,105],"layer_role":"movable"}]}
```

**第二步，按自己的观察生成一张图。** 阅读[共同制图入口](first-submission.md)。从自己的标数及端点做好两轴比例。每个源图标记要能找到自己的 CAD 对象。给图块写出类别、常规宽深、使用朝向和接触边。按[宿主实墙放置](hosted-family.md)把床头、柜背贴在实际支持它的那一面。厨房水槽与灶台按真实台面轮廓支承。检查每扇门开启的整个扇形和每把餐椅退后的占地。只对来源明确的出入口放门，避免用图片中的干扰线制造额外实体。生成工作 DWG，分层回读，制作原图叠图和纯 CAD 图。

**第三步，看保存后的图。** 每个区域并排打开无标记原图、原图叠图和纯 CAD 图。从入口再走一遍；看床柜背面、门扇和柜角、台盆支承、餐桌四周、收纳转角、卫浴使用面是否能成立。用以下命令核对第一步从原图点取的位置。它实量过洞探线、指定色层的实墙芯、平开门铰侧和扇端，并查家具点处的块。一个点命中家具块外框，仍须肉眼确认类别和件数。弧墙、异形扇及自定义家具按原生几何补测。对照中若发现此前漏识或误识，保留原观察及更正理由，回到对应对象调整后复开；不能清除原探线或修改容差来消掉红项。每个有明确错误的对象都在交首稿前处理。源图确有歧义处记录读法、依据和余差。

```sh
python scripts/recheck_source_marks.py 回读/readback.dxf registration.json observations.json 自检/原图逐项 --pictures 原图.jpg 原图叠图.png 纯CAD线图.png
```

盲测交接中，三个阶段用同一预写任务说明。第一步交给执行者本人留存的原图观察，第二步的工作模型只供本人自查，第三步结束才提交首稿；外部评审各阶段均不向作者提供反馈。少数图符不清但能解释时如实记录；不能把源图可辨、实际堵门或缺件写成不确定。
