# 批量复量床头、柜背，并在新 DXF 中贴墙

已有图的放置位置可能含小数舍入误差。保存后，按本图原始功能和朝向登记应贴墙的床与柜。程序从当前 DXF 逐件读取外缘、真实墙材和门窗。原图像素只用于认物。不要把像素误差、打印线宽或 5–10 mm 的室内尺寸取整当作共边容差。

## 一次登记，多件实测

使用当前 DXF 配套的[毫米结构台账](color-guides.md)。其中应含 `wall_layers`、`walls` 和 `openings`。每个洞口要有净洞端点、墙或框厚以及与当前图匹配的 `symbol_handles`。平开门要有实际门扇和开启弧。已核实没有洞口的局部合成图可给空数组。先确认台账完整覆盖实际图中的门窗。转存 DWG 改变句柄时，先在新回读中重新定位图符。

从原图独立登记每件床或柜的用途、近点和朝向。已有 `place_hosted_family.py` 放置表可复用同名字段。下面是合成登记的字段示例。近点、句柄、名称和移动上限须用本图实值替换。

```json
{
  "max_move_mm": 15,
  "max_slide_mm": 8,
  "source_to_mm": [8, 0, 0, -8, 0, 4000],
  "items": [
    {"id":"床甲", "family":"bed_double", "side":"-y", "near_px":[70,45]},
    {"id":"柜甲", "family":"cabinet", "side":"+x", "near_mm":[2500,1200]},
    {"id":"转角柜", "family":"corner_wardrobe", "handle":"B8", "side":"-y",
     "host":"北墙", "return_host":"西墙"},
    {"id":"留空柜", "family":"cabinet", "handle":"C4", "side":"-y",
     "exception":"原图标出背后安装管槽"}
  ]
}
```

- `family` 可用 `bed_single`、`bed_double`、`cabinet`、`corner_wardrobe`。后两者分别为直柜和 L 柜。目录床、原生直柜和 L 柜通过实际块识别。两种目录床都自动取圆角床头两切点间的真实直边。L 柜自动取两翼外背，支持镜像和旋转。
- `side` 指从墙向房间的 CAD 世界方向，也是床尾或柜前的方向。可用 `+x`、`-x`、`+y`、`-y`，或给二维向量。另可给反向的 `toward_wall`，两种写法选一个。已知目录块可由当前块的原始朝向计算。源图与块的朝向冲突会报待核。
- `near_px` 需配 `source_to_mm`。也可给 CAD 世界坐标 `near_mm` 或本图顶层 `handle`。近点宜落在目标物件内部。多个同类物件等距时需改选。缺省拾取半径 250 mm，可用 `pick_radius_mm` 修改。另有通用柜时，给 `side` 后可凭近点识别固定家具层上具有真实矩形或直角 L 形外缘的独立图元、块。自定义固定柜层通过 `cabinet_layers` 指定。已有句柄时可直接选择。普通床块应由执行者确认床头身份，再给句柄与朝向。
- 自定义柜体可用一条闭合多段线或能包住细部的一条真实外轮廓。多实体轮廓需按[实物外缘选取方法](wall-contact-fit.md)登记 `physical_outlines`。该件只允许刚性平移。异形、点靠、活动靠垫或高度相错需要看图判定。给 `exception` 说明有意留空的图证。例外件留在原位，实际墙内侵入、门扇和相邻硬物干涉仍会报待核。
- `host` 和 `return_host` 可分别指定已有台账中的真实宿主，适用于邻近多面平行墙、错台或歧义位置。不指定时，在实际背边附近寻找法向相符且距离最近的真实墙面。缺省查找距离 300 mm，可用 `wall_search_mm` 改。查找距离只影响认墙。
- 图中宜标全相关硬物层。程序通常使用台账 `nonwall_fill_layers` 并包含标准活动家具、固定设备、建筑附属及门窗层。自定义硬物层可在 `hard_layers` 列齐。原生家具被当作障碍计算。对无法验证闭合占地的图元，用其原生范围作保守筛查，发生重叠时报出句柄。复杂嵌入关系、垂直净距和未登记的自定义物件需另核。

## 运行和读数

```sh
python scripts/repair_wall_contacts.py 已存毫米图.dxf 当前结构台账.json 靠墙登记.json > 原位实量.json
python scripts/repair_wall_contacts.py 已存毫米图.dxf 当前结构台账.json 靠墙登记.json --write-new 靠墙调整.dxf > 调整复量.json
```

第一条只读。逐件看 `before.backs`。同一毫米偏差在多件上重复时，看 `repeated_normal_offsets` 中的物件和背段列表。共同偏差的成因还需从绘制记录判断。

| 报告字段 | 如何判断 |
|---|---|
| `back_mm`、`actual_endpoints_mm` | 当前图中实物直背长度和两端的世界坐标。L 柜两翼各列一项。 |
| `normal_gap_mm` | 正数表示留缝，负数表示侵入墙面。只有 CAD 计算舍入界限 0.00001 mm 可作零处理。 |
| `physical_contact_mm`、`longest_continuous_contact_mm` | 真实共面的接触总长与最长连续接触长。只要背面有缝，两个值都是零。 |
| `wall_solid_projected_mm`、`unsupported_intervals_from_back_start_mm` | 背后实墙的投影覆盖和局部缺段。柜背跨洞时可据此沿实墙核查两端。 |
| `endpoints_in_contact` | 两个端点各自是否与墙的真实支承区间共点。中部断墙仍靠全部区间判定。 |
| `body_in_wall_mm2`、`hard_collisions`、`uncertain_obstacles`、`openings`、`opening_symbols`、`door_swings` | 整件侵墙面积、相交硬物句柄、占地待核句柄、洞口和真实框线、门叶及开启扇区冲突。面积计算舍入界限 0.0001 mm²。 |
| `unregistered` | 图中目录床、原生直柜及 L 柜中尚未登记的句柄。自行绘制的未知物件仍须从原图清点。 |

`in_contact` 表示原位全长贴墙且检查范围内无干涉。`repairable` 表示找到允许范围内的位移，`after` 是计算位置，`before` 保留原位实量。`pending` 表示需要核图，例如实墙太短、侵入开启区、相邻柜阻挡或两个修正位置等距。缺明确墙面时，未能实量的接触字段为 `null`。`intentional_clearance` 保留登记依据及原位实量。

新图只平移已登记物件。缺省总位移上限 20 mm，沿墙上限 10 mm。可按原图定位精度缩小范围。先求真正共面的法向平移，再找能在同一连续实墙上容纳整段背边的最短调位。L 柜两翼共用一次世界坐标平移。只检查已登记的墙、洞、实际门扇、开启区、门窗图元和所列硬物层。沿墙候选来自墙端、物体外端及相邻硬物的投影边界。复杂避让或需要改变布局时保留待核。

默认有待核或遗漏目录件时不发布新图。可用 `--write-new 新文件.dxf --partial` 把已证实的局部修正保存到独立副本。其余物件留在原位，报告继续标明待核。工具先写临时文件，再复开读取实际图元。已调物件和原先合格的物件全部通过后才发布目标文件。读回实量见 `readback.items`。输入图及已有目标文件不会被覆盖。

退出码 0 表示现有图已通过本次登记项目，或完整修订已经保存复核。1 表示只读检查发现可修误差、尚有待核或输出为局部修订。2 表示输入、结构台账、文件写入或复读存在错误。真实 DWG 经另一转换器读回时，应使用该回读及重新核对的句柄再测。功能关系与实际施工构造仍按原图独立审阅。

## 合成平面实测

在带小数坐标的原生实墙、两个窗洞和一扇平开门中，运行只读、完整发布、局部发布及独立复开。结果如下。

| 合成输入 | 当前 DXF 与输出 DXF 的实量 |
|---|---|
| 单床背缝 0.01 mm、双床背缝 8 mm | 原位接触为 0。复开后圆角间直背分别连续接触 863.6、1422.4 mm。 |
| 两个紧邻直柜同留 7 mm | 两件原位均测得 7 mm。复开后分别全长接触 500、300 mm，无重叠。 |
| L 柜两翼分别留 9、5 mm | 一次平移 (−5, 9) mm。复开后两翼分别接触 1000、900 mm。另测右手返回翼、镜像和 90° 旋转，复开两翼通过。 |
| 300 mm 直柜背后仅有 295 mm 实墙，且法向留 8 mm | 沿墙 5 mm、向墙 8 mm，保存后 300 mm 连续支承。 |
| 800 mm 柜横跨两窗之间的 700 mm 墙段 | 记录 700 mm 实墙投影；允许的平移范围无整段支承，保留待核。 |
| 柜侵墙 0.01 mm、定制镜像直柜离墙 5 mm | 前者报告负间距，后者按近点匹配实际矩形。两件均复开确认零缝。 |
| 门弧扇区内的柜、与硬物交叠的柜、注明有意留缝 15 mm 的柜 | 前两件保持原位并报待核，即使门扇停留位置未碰柜也能识别扫掠干涉。第三件保留原缝和依据。 |

包含待核件的试验没有生成完整发布文件。显式使用局部发布后，重新以独立只读命令检查该文件，已调物件全部通过。输入 DXF 的 SHA-256 检查值相同。另一个全合格的镜像转角柜样本通过完整发布及独立复量。
