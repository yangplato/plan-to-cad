# 从成品审图

V1.6 作业使用[分型观察、独立清点封存和一次集中修正](workflow-v16.md)。早期作业的字段与命令保留供复查。

## 先冻结读图

先读原图。把每个洞的位置写在对应墙边。分别记门垛、门扇数、铰链侧、门的去向。记录楼梯两端、平台、断线、上行箭头。设备井逐边查检修口。对连续窗、栏杆和隔墙，记录内框、外框、各轨转折和实际端头。缺证据的部位写明推定。固定原图读数后再建模。

## 用同一几何画相邻构件

- 墙角。在 scene 的 wall_junctions 中列 members。每条含 wall 和 end（a 或 b）。工具用两条墙轴求公共点，随后生成墙面。两墙偏轴或柱子凸出时，单画实际边界。复量凸角的两条外边。
- 折栏。在 frame_paths 中按同一方向列 openings 和 offsets_mm。各段按首尾顺序相接。同一道轨共用转折点。逐根检查内道、外道和两端。仅在真实封头处启用 cap_start、cap_end。独立作图入口为 drawing_junctions.draw_frame_path。
- 门洞。先切墙，再从铰链一侧的实际墙材求门轴。两侧厚度分开量。普通门用 bind_hinges。使用带安装偏距的框时，按实物画框，验证门轴接框、框接墙。再看门扇完全开启和整个开启过程。修正门轴后同步修正门扇、门弧和净开宽。
- 楼梯。按原图区分折断线与折断带。有带宽时，将两条边和本跑各踏步交给 drawing_junctions.draw_stair_break。函数剪去带内踏步。检查另一跑和上下平台的实线、虚线及箭头。
- 家具。先认使用面、占地和相邻件，再选图库块。核实底柜占地是否给冰箱留位。核实转角柜的两个柜段是否接边。桌边椅、台面上的盆、床垫和床架允许有用途明确的投影重叠。

## 第一遍只看成品

审图者只看同版纯 CAD 与原生回读。有纯线 PDF 时可一并查看。关闭底图。先看整页，再放大节点。检查下列四项。

|观察对象|检查动作|判断和处理|
|---|---|---|
|墙、门垛、栏杆、长窗|沿每道外皮走到头。量两侧实墙。隔墙正对窗时量到本截面的内框。检查每个转角有无缺料、重线或横穿线。|图元相接可实量。疑似柱凸、材料分界或安装缝，记位置和两个可能解释。|
|门、通行、检修|沿入口走到每个房间。逐扇检查门轴与门框或墙、门扇与弧端。看开启是否穿墙、撞柜。检查移门两端和检修门的操作侧。|另画短框确实接墙，可支承门轴。量最近实墙的结果单独不能证明门悬空。确实相撞时，记录进入深度或重叠区。|
|楼梯、井道和家具|顺着梯段读踏步、折断和行走方向。看井道开口能否使用。对相邻柜、床、桌、椅逐件看实际轮廓。查实线交叉。再查一件家具是否完全落在另一件占地内。|缺方向依据、分不清设备性质或不知道两件是否同高，记作待核。图块名称和外包矩形只用于定位。|
|图纸|用正常 A3 阅读大小看房名和尺寸，再看密集局部。沿每条引线走到端头。|引线穿墙、窗或房名时，移动房名或改线。核图框、比例、字高和线宽。模型标注保留青色。|

用 `python scripts/check_cad_logic.py readback.dxf --json candidates.json` 筛查。该工具只读 CAD。每一项含位置、图元或测距。退出码 2 表示有待审项。脚本中的短距离范围只用于找疑点。未知实体、无可读墙或遮蔽的结构层须补查。逐项保留实量正常例。先记录明确错误。封存盲审，随后完成源图对照和整户复量，再统一发回一次返修。人工盲审须查脚本未覆盖的画法和使用关系。

`review_working_plan.py` 读取同一作业的 review/cad-only-frozen.json。先在临时 observations.json 中记录盲审。填写 reviewer、dxf_sha256、junctions、access、symbols 和 sheet。各项用一句话记位置与实际观察。dispositions 以候选 id 为键。核实正常项填 status 为“可接受”或“已核实”，在 evidence 中写图元和量值。需要原图判定时填“待对图”，在 evidence 中写疑点。将确认的未修错误以唯一字符串 ID 列入 open_defects。独审者完成两阶段审查后，按同一 ID 合入 issues 的 repair 项。纸张、笔宽等打印偏好另记。换版后重新检查。先用下列命令冻结观察。已有文件时，此命令会停止。已确认的错误须修图，再对新图重新冻结。冻结后才打开原图。

```sh
python scripts/check_cad_logic.py readback.dxf --freeze observations.json --json review/cad-only-frozen.json
```

## 第二遍叠原图

对盲审中标为“待对图”的候选，可在独立验收记录的 cad_source_recheck 中补 source_sha256、dxf_sha256，以及该 id 的 dispositions。核实正常时填“可接受”，附来源位置和实量。保留冻结的原始判断。确认有错时修图并复开。

原图明确的门洞所在边、叶数、楼梯折断形式、井道开口及柜体用途逐一对照。由原图判断是否漏画、有无认错。局部来源模糊时保留推定。把墙面、控制线、净距的实量与冻结的预期比较。改一处后复量相邻件，再看新的纯线图。默认只交用户要求的文件。
