# 在原图登记的洞口内回读门、窗和栏框

先从原图逐洞记录两个端点。相邻卧室窗和阳台移门分别给 ID。短固定透光段能看出独立两端时，可单列为窗；若属于移门整樘，可将其计入可辨扇段下限并保留局部原图。读差应取自原始像素。门扇、轨道看不清时，省略对应数量。种类本身也有歧义时填 `symbol_legible:false`。读图记录和坐标登记在建图前保留。

下面的数字只用于说明字段。坐标原点在原图左上，a 和 b 为原图洞口两端中心。登记矩阵与其他首稿检查共用，顺序为 `[a,b,d,e,tx,ty]`。层名取实际 DWG 的登记值。

```json
{
  "source_sha256": "实际图片摘要",
  "portals": [
    {"id":"卧室外窗","kind":"window","a":[20,60],"b":[120,60],"uncertainty_px":1},
    {"id":"阳台推拉门","kind":"sliding","a":[140,60],"b":[340,60],"uncertainty_px":1,
     "min_tracks":2,"min_panels":2,"end_support":["wall","wall"]}
  ]
}
```

- `kind` 可为 swing、sliding、window、rail、open。`min_tracks` 和 `min_panels` 只填原图可辨的下限。平开门可按原格式给 `leaves:[{"hinge":[x,y],"tip":[x,y]}]`，分别实核原图铰点和开启扇端。
- `uncertainty_px` 为本洞读差。整张图在相同分辨率下量得同一读差时，也可用文档顶层 `band_px` 或命令参数 `--band-px`。缺少读差的条目保留为待核。
- `end_support` 可选。依次对应 a、b，可填 `wall`、`frame`、`free`、`unspecified`。要区分短墙垛与邻框时，应独立记录原图可辨的支承类型。可另填 `wall_thickness_mm` 记录已知墙厚。例如边栏两端均无墙时，应给出可核的框深和两端条件。
- `registration.json` 需要毫米变换和 `layers` 中的 bearing、partition、door、window、ancillary，其他图层沿用实际配置。有明确的非填充墙材规则时，可在此文件中配置既有 `wall_layers` 解码模式。层为 0 的块内线继承插入层。块内单独命名的线按其实际图层检查。

```sh
python scripts/check_registered_frames.py 回读/readback.dxf registration.json 独立读图/source-reading.json 逐洞回读.json --source 原图.jpg --svg 洞口定位.svg
```

先用 `native_readback.py` 保存并复开 DWG，使用本次生成的 DXF。检查程序也可用于普通已保存的 DXF；报告的 `sha256.dxf` 指向实际送检文件。原生保存和复开记录由 `capture.json` 给出。传入 `--source` 时会比对原图文件摘要。程序遍历模型空间，展开普通二维块、嵌套块及阵列块，读直线、多段线及圆弧。它不读取制图者自报的洞口句柄。

## 查看实量

每行保留原图像素、对应毫米坐标、容差、两端附近三道墙材断面、净区墙材面积、各层实际线段及其句柄。块内定位为顶层插入句柄加块名和成员序号。`by_layer` 内的毫米坐标按 a → b 方向和向左法向表示。附图逐洞标出登记两端、墙材和实际线。对照独立原图局部，确认读图记录本身的种类、洞宽及归属。

- **窗和栏框。** 量两条以上有间距的原生平行线，检查两端有能连接这些线的端框。重线只计一条。窗与栏框的常见线形相同，程序同时检查实际归层和独立来源所记种类。归层或功能无法由原图确认时，记为待核。
- **移门。** 量本洞的贯通轨、两端、各段窄扇轮廓，以及成对的错轨扇是否接续覆盖本洞。允许同一轮廓由多个独立 LINE 构成。扇的两条边均须有两端横线闭合。只见贯通的轨线而看不到应有扇段时，检查报失败。自定义图例仅用错开的单线表示扇、使用曲线或可变块而无法完整展开时，查看局部原图、库块和原生实量，再判断等效表达。程序不会用相邻洞的扇补本洞数量。
- **净洞与遮挡。** 在原图两端读差以外，对洞内两侧墙面之间的整条净区求实墙交叠。另沿原生框线与各扇中心线量压墙长度，检查短固定扇及洞端。两端墙材探线分别记录其毫米坐标和厚度范围。清晰图证与实际实墙冲突时应改图。仅留下洞口、把两个图符互换、错层、只画一条重线，均能在相应洞口定位。
- **平开和净开口。** 平开门需在本洞量到同一铰点的弧和实际扇边，并检验关闭投影覆盖洞宽。已给铰点和扇端的，逐扇对位。净开口内出现完整门、窗或栏框时标错。附近只有端头、门槛等局部线时，在局部图中分别核对。
- **结果范围。** 退出码为 0 通过、1 失败、2 待核。低分辨率、未解实体、重叠登记、异形图符、无法确定的墙面及端头，保留原因。图符几何吻合仍须核对开启方向、门扇运行空间、窗台高度或两侧所接房间；缺少这些源图信息时不据此推定。框线在洞内的吻合也不能证明独立原图清单没有漏项。

## 合成核验范围

同轴窗及移门、二者交换、净洞缺符号、重线、仅有两条轨、窗后实墙、短固定端扇被墙覆盖、图符错层、少一扇、嵌套库块拆成独立 LINE，共十种工况。合并保存 DWG 并复开后的二十个登记位置均与预期相符。另以独立保存的合成 DXF 检查常规平开门、开启扇端反向、栏框、净开口和低清图符。上述结果只验证这些合成工况。
