# 从原图把已读清的墙色写进首稿

已有本张营销图的墙、洞和两轴标定后即可运行。房间、家具和尺寸可以稍后补齐。输入现有的 [墙芯取样 guides](color-guides.md)、原图、配准及首稿 scene。输出一份逐墙色段表和一份可用共同建图入口重建的 scene 工作副本。这里的 `bearing` 和 `partition` 指本案图例所对应的两种印刷墙色。

## 一次运行

1. 在本张原图的实墙芯内取两组颜色。标长轴、常见芯宽及搜寻范围。图中明确的洞口写在该轴的 `openings`；家具或文字用 `exclude_boxes_px`，阴影、水印等用本轴的 `review_spans`，如 `{"span_px":[84.5,95.5],"reason":"watermark"}`。两份不同材料的笔画在像素上完全同色、同宽时，须由绘图者按图例、门框和周围陈设辨认。
2. 如果委托已允许还原初稿中暂定的印刷墙色，在 guides 顶层列出相应的原墙 ID，并记下已有授权依据。一个母轴可对应多个原墙 ID。未列出的墙也会收到有位置的建议。已确认结构墙可在 scene 顶层登记 `confirmed_structural_wall_ids`，或在该墙上写 `"material_locked":true` 或 `"structural_status":"confirmed"`。上述锁定优先于暂定清单。有实际承重调整、墙厚变化或房间布局决定时，依项目授权另行处理。
3. 配准输入使用共同入口的 `registration.json` 格式。至少包含 `source_to_mm`、`holdout_limit_mm` 和独立的 `holdouts`。scene、配准或两者须记录原图的 `source_sha256`。已有 scene 同时包含这些字段时，两个位置都可传同一份 scene 文件。两种方向的读差应来自本图，可以不同。

以下为 guides 授权字段的格式示例，墙号和依据要换成本案实际记录：

```json
{
  "printed_tone_scope": {
    "provisional_wall_ids": ["N1", "W3"],
    "basis": "本案委托允许按原图印刷深浅修正这些初稿暂定图层。"
  }
}
```

```sh
python scripts/apply_wall_tones.py 原图.png guides.json registration.json scene.json 临时/墙色工作 --read-band-px 1 --normal-band-px 1
```

`--read-band-px` 是沿轴读差；省略 `--normal-band-px` 时两方向取相同值。输出目录须为空或尚不存在。没有授权清单时，脚本仍写出逐墙建议，工作副本与原始 scene 内容相同。

## 看表和建图

- 打开 `wall-tone-schedule.json`。按 `walls[].wall` 找原墙，再看 `axis`、`intervals[].span_px`、`label`、`status`。水平轴沿原图 X 向右，竖轴沿原图 Y 向下。像素 79 与 80 的共边是 79.5。轴下的 `source_axes[].runs` 保存稳定区两肩实际 RGB 和横剖样带的位置，`protected` 列出实际洞端和相交墙保护范围。
- `applied_to_copy` 表示有授权、有足够连续墙色且原草稿与之不同。`matches_draft` 表示该区已相符。`suggest_only` 表示源图可读，保留现有墙层。`review` 须回原图看该段及两端。两色隔着渐变、水印、图符或短纹，换色位置仍待读；脚本不会把遮挡边缘当成精确的换色点。
- 在 `job.json` 中把 `scene` 指到 `scene-working.json`，仍用同一份 `objects.json` 运行 [共同建图入口](draft-from-schedule.md)。只查看结构时也可直接运行 `python scripts/build_observed_structure.py 临时/墙色工作/scene-working.json 临时/结构.dxf 临时/结构台账.json`。给房间、标注和家具补资料后可继续用同一份工作副本。若修改墙、洞、原轴标定或相关图层，回到修改后的基础草稿和原图重新计算色段。
- 工作副本的 `walls` 保留原始逻辑墙、中心线、厚度和端帽。顶层 `printed_wall_tones.spans` 是实际生效的分色记录，每条保留原墙 ID、母轴、起止站与目标颜色。当前建图入口先按原宿主扣洞，从原生墙材面切出对应区间并生成闭合轮廓与填充，然后在墙材上绘制门窗和标注。门窗和家具仍用原 `hosts`、`host` 或 `support_segments`。带分色记录的工作副本需用本版建图入口。由旧工具单独读取 `walls[].material` 只能看到该墙原始底色。
- 建图后保存并复开，对照 [墙芯分段实量](wall-tone-stations.md) 和原图。输出报告中的 `applied_to_copy` 是建图输入状态。已建实物是否吻合由保存文件的独立实量确定。

## 自动应用的边界

工具在原图里沿引导轴逐站检查横向至少三条芯内像素。再核对该处与既有逻辑墙的轴向、墙心和宽度。芯宽差以实际读差及一个像素量化误差控制；法向读差达到半个既有墙宽时保留待核。每段独立实墙上的稳定两肩至少覆盖 4 个像素、1.5 倍芯宽以及两侧沿轴读差。只有可见换色点、实墙端或明确洞端能确定分段边界。一段确有稳定墙色但有一端消失在遮挡中，报告保留该段，工作副本不采用这项推断。

按物理宿主分段扣除窗洞、门洞和多个墙体实有的交叠面积。跨两墙宿主的门窗、相交轴中央都不会被色段填回。实际端帽也属于核查范围。引导线没有覆盖到的端帽保留原色。斜墙、弧墙及未登记轴的墙线须另行判读。

## 合成样例实测

- 在一根旧墙上写入两段浅色。跨第一处分界的直柜仍引用同一个旧墙 ID。旧图与重建 DWG 都测得柜背 700 mm 全长贴墙，间隙为 0。
- 一扇窗跨两个旧墙 ID，洞左右的实体墙色不同。保存并重新打开 DWG 后，窗净宽 400 mm；另一扇平开门净宽 700 mm。两处净洞统一穿透。门扇、开启弧、窗线、独立栏杆及原生尺寸的几何一致。新旧墙体并集对称差为 0 mm²。
- 带 T 交接的墙只改两侧可辨实墙，交轴中央保持原色。短纹、未取到样色的阴影、登记的水印及家具遮挡分别保留待核。已锁定墙与授权外墙产生建议，工作副本没有改色。
- 另一例的 X/Y 比例分别为 13、17 mm/px。反向登记的竖墙及其显式端帽在保存复开 DXF 后分界正确，另一根未看全端帽的墙保留原色。失效的比例留出点会中止生成；基础墙厚改动后，旧色段表会被拒绝重放。

以上数字来自独立构造的图样。实际营销图应记录本图的取样位置、图例和不可辨区域。
