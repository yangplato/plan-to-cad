# 成图后的整户专业审查

审图者先从营销原图列出空间，再与绘图清单逐项核对。把玄关、客餐厅等开敞空间的不同用处分开查看。电梯厅、阳台及楼梯等会影响本户的边界也须覆盖。

沿每个空间的内墙面走一圈。经过墙柱、墙厚转换、窗框、转角和门垛时，顺墙向前和向后看两侧的实际边线。对照原图辨认真实的柱凸、构造缝、包框和墙芯变厚。另看靠墙的孤立柱块与两面墙是否有细缝。自动筛查沿墙材外轮廓找短台阶，默认找 25 mm 内的横向错台；设置仅决定列出哪些候选。孤立柱与墙之间的缝、隔着门窗的两段墙、曲墙及更大的错位仍需审图者定位。已确认的 15 mm 厨房门垛等真实构造可保留。

源图与成品使用同一截面和同一对象身份。相邻墙先求实际墙材交集与并集，再量两面、厚度和中面；两段各自厚度正确，不代表并集正确。若新增控制线没有穿过自述的墙中面，记录偏移和依据，不把它直接当工程轴线错误。只有标数对上、实际面缺失或净区仍含墙材时，不能通过。

逐房复核两个方向。围合方向量净距，合理开敞方向按下文登记。有疑问时在附近再截一刀。量厨房时把墙到墙的净宽、柜体深度和柜前走道串成一条链；卧室检查床头、床侧、衣柜开门与入口；餐厅按拉椅和通行范围检查；卫生间兼查门扇与洁具。开敞区与凹形空间应指明截线的位置。登记实体边到实体边的毫米数。制造尺寸、圆弧长度及图像的像素换算尾数有不同含义。对未标建筑尺寸，以总长、相邻端面和使用方式选择整数设计值。

净距按该截线真实功能面取数。玻璃框、门轨、门片、墙面和柜前沿分别登记；名义洞基准或包围盒不能替代实际内面。源图为开放入口时，检查实际净区无误加墙；没有第二堵墙就写开敞跨度，不借邻墙延伸伪造墙间净深。成品缺相应边界时记缺边界，不能用参数表补出一个通过值。

锁定项目明标、已确认的尺寸链、结构控制面和布局。改动推定墙位前，列出同一面的所有受影响部件，包括对侧净距、门垛、窗框、栏杆、柜背和量尺。在营销图复刻的授权内，证据和全局约束支持同一修法时自主处理。涉及超出授权的已确认构造、标数或布局时，说明缺少的依据和可行取舍。改后在原截面和相邻控制处复量。

## 叠图核实图意

按主图独立清点窗间实墙、平台短柱、朝向家具和未封闭通道。沿室内外两个方向追踪框线。查看隔墙是否终止于正确的外墙内框，转角栏杆和邻柱是否先后遮住彼此。对模糊边界放大原图，同时看关闭参照后的纯线稿。有同页小图时可用来确定空间关系，并注明两个视图表达不同的地方。桌椅朝向与摆位可按桌边和座面逐席比对。记录证据支持的判断；对原图看不出具体做法的部分保留推定。

通过扫描只能说明在当前阈值和图层内完成了相应量测。一樘窗可以洞宽正确而漏掉端部实垛，一排柜也可以外包线贴墙而真正的板边仍有缝。问题最早可预防的阶段、实际发现方法及复开证据见[三步核对](stage-checks.md)。

## 在全局尺寸稳定时减少小数

**先确定量的是什么。** 标出量取方向、起止端面和用途。区分项目明标、用户确认的设计值、指定产品的实物尺寸、图片估读值、用于检查的现场 CAD 量尺。量尺随几何更新。同一刻线量到轴线或墙面时，分别计入半墙厚或整墙厚。

**先建立控制链，再选局部值。** 固定有依据的总长、已证实的工程轴或营销控制、相邻户或井道的共用面、已确认的部件及布局。列出控制面之间依次遇到的墙厚、墙垛、洞口、柜深或通道。图上估读有尾数时，用局部刻线换算每像素的毫米数，考虑线宽和同一刻线的辨认误差。几何可同时符合多个值时，优先能解释部件规格、工艺、使用净空、共线和重复关系的整数或名义规格。保留改动最少且有使用依据的方案。家具自由摆放产生的自然间距、曲线展开长度、旋转坐标或厂家精确尺寸可保留小数。

**把候选放回整户。** 沿同一方向验证各分段之和等于两控制面之间的总长。按实际情况验共享墙的另一面、墙厚、对侧房间和垂直方向已标尺寸。每段分别四舍五入可能会吃掉门垛、造成墙面错台或挤占邻室。固定外端之间含小数时，先找到余数来自哪一项。按证据调整推定端面，或原样保留并说明。禁止用单改标注、改变显示精度或把余数藏进邻室通过审核。

**执行与交付。** 为这次拟改写明取值依据、固定面、移动面、方向和毫米数，具体列出联动的墙、门窗、柜体、楼梯、家具或量尺。先核定本案授权。营销复刻中，墙层颜色表述图上类别，局部墙位仍可能是像素推定。若用户授权按规则自主判图，原图边缘、全局尺寸、房间使用和相邻构件共同支持同一修法时，自主修正并复开验证。实际施工、复核实测资料或明确锁定控制面的变动遵照对应授权。每项未决在交付摘要中说明实量、建议值、移动量与牵动对象，标明尚未落图。原生复开后在原截面和不同的相邻控制处实测。逐一回查已批准的总长与印刷分段。核对块内真正承担功能的边与宿主端面，复量垂直方向的规格、进深和净空。确认共面、贴墙和通行关系。

## 全面检查的覆盖边界

从原营销图独立清点空间、全部洞口与实际墙柱转角。用保存后的模型扫描全部原生量尺（含新加量尺、隐藏层和块参照内的量尺）。已有建筑外围标注由原生分段和总尺校验。其他线性量尺逐条核对真实定义点、对应物理端面与数值。重复量尺也要逐条回量。角度、半径等按自己的表达另验。未加量尺的门窗、建筑接头和房间截线仍按上文审查。手工以线和文字拼成的标数、栅格图中文字、未加载外参及非原生代理对象要由读图者补列；读不到的部分单列范围。

清单数量按本图生成，不固定为历史案例的分段、墙面或房间条数。分别记录应查、已查、失败、待核和不适用；每项绑定源图对象、终稿哈希、实际句柄与截面。已知失败先报，不能用通过项数量抵消。V1.5 的打印检查单独报告，验法见[判定与回读](acceptance.md)。

沿同一基准面追到两端、对侧与邻室。把有相同偏差根源的全部房间净距、门垛、洞端、图块和量尺登记到同一处理项。只修一条量尺的显示，或者只修其中一个房间，都不能关闭这项。保留产品规格、明确构造间隙或浮置家具位置时，说明实量为什么合理。图层名和标注精度不能单独作为保留理由。仅在证据支持不同构造且无法排除其一，或既定硬约束要求互相冲突时提交取舍。写出缺失证据、可选处置以及各自影响。门槛检查覆盖范围和实测证据，审图者仍负责构造判断。

## 记录与运行

V1 的独审记录和修订稿复查记录在顶层写 `overlay_review`。原图哈希对应本案最初收到的营销图，DWG 哈希对应此轮实际叠看的文件。原图哈希也要写在 `ledger.source_sha256`。修订后重读并更新新稿的证据。早期格式仍覆盖各自版本声明的内容。

```json
{
  "overlay_review": {
    "source_sha256": "<原图 SHA-256>",
    "dwg_sha256": "<本次 DWG SHA-256>",
    "observations": {
      "junctions": "填写有代表性的柱窗端、隔墙或栏杆位置，说明原图与成图如何接合",
      "furniture": "填写桌边席位、椅子朝向或分段接边，说明实际对照结果",
      "uncertainties": "填写仍受像素或遮挡限制的部位、保留依据，或说明为何可关闭未决项"
    }
  }
}
```

示例文字为填写提示。程序核对文件身份和证据栏，审图者负责实际切换叠图、放大局部并填写结果。

绘图入口为新作业生成 `review/整户专业审查候选.json`。在独审/复查 JSON 的 `professional_review` 写入下列字段。复查记录对应改后 DWG；候选坐标也使用这一版。

- `source_rooms` 为审图者独立从原图清点的空间 ID。与工作稿 ledger 中的房间 ID 使用相同名称。发现漏画时追加原图空间，并登记问题。
- `rooms` 每行含 `id`、`faces`（墙柱与开口的具体接点和判断）、`use`（家具、开启和净空的具体观察）及 `spans`。每条实量含 `between`、`points_mm`（两端实际平面坐标）、`handles`（两端所属实体或块参照句柄）与 `mm`。例如一条横向量取可写成 `{"between":"厨房浅墙端至地柜前沿","points_mm":[[11000,3200],[12100,3200]],"handles":["A8","2AA"],"mm":1100}`。句柄、位置与房间名按本案替换。优先选墙柱闭合轮廓、窗框、柜块或实体边。小数实量必须用 `issue` 链接处理依据。
- 对实际选定设计值并调整的尺寸链，在绘图 scene 或既有 CAD 的 ledger 预先登记 `rounding_chain_ids`（唯一事项 ID 列表）。审图者按相同 ID 在 `professional_review.rounding_chains` 对象下写入 `basis`（来源、取值依据及图片精度）、`fixed`（保留的控制面）、`change`（运动方向、量与联动对象）和 `checks`。每条检查填 `between`、同截面依次排列的 `points_mm`、对应的实体 `handles`、各分段设计值 `segments_mm` 以及独立确定的 `total_mm`。第一条量改动链；再选实际受影响的另一条截线或关联尺寸，如两端之间的分段、墙厚、相邻房间或柜体背后的接合。数值依据取自修改前保留的控制或已批准的调整。脚本校核每段实量、总长与分段合计、端点和不同的检查对象；审图者核对输入的控制值与项目依据。旧案未登记取整改动的审查记录仍可回读。
- `steps` 用候选完整 `id` 作为键；值含 `evidence` 和 `result:"保留构造"` 或 `issue`。给出原图可见关系及读回实量。已确认错误用 repair，需要用户决定用 decision，有依据且宜保留的推定用 inference。正常作业在外层 `issues` 或复查记录中关联这些事项。
- v0.15 的既有 CAD 审图在 ledger 填 `drafting_version:"0.15"`。新案自动填入。扫描输出的 `rulers` 中，每个非外围量尺在 `professional_review.design_rulers` 以句柄（块内为实例路径）登记 `between`、共用的 `group`、`mm`、`handles`（两端所在物理实体）。碎数写入所关联的 `issue`，说明修、保留或真实歧义。非线性量尺填写 `method` 和 `evidence`。线性量尺出现过时定义点或覆盖数字时补测和更正。不以改精度关闭。
- `source_openings` 清点原图全部门、窗、栏杆和敞口；`opening_reviews` 以洞口名称登记全部符号实体 `handles` 与现场核查 `evidence`（敞口填写两侧真实边）。对每樘门、敞口、窗和每段栏杆，分别在 `sections` 登记“洞宽、首端、末端”三次实量，各填 `between/points_mm/handles/mm`。窗/栏杆的“洞宽”按框端或栏杆轴线端之间的跨度测量。两端沿墙面量到下一处真实接点；框接框、连续墙与独立短垛分开说明。无独立门窗垛、两件直接相接时，填 `joint`（“框接框”“转角接头”或“直接贴实墙面”）、`point_mm`、相接两实体的 `handles` 及证据。真实自由端填 `free_end:true`、实际收口的 `point_mm/handle` 与 `evidence`。碎数关联已登记的 `issue`。成图中门窗层的图形也需逐一归属。自定义业务层可在 ledger 的 `opening_layers` 指定。对每一个 `kind:"decision"` 填 `unresolved_evidence` 和至少两项 `alternatives`，说明实质证据差异和处置后果。
- 入口验证房间覆盖和两个方向。围合方向须提供实体端点。V1.5 独审者为每个空间写 room_use（实际用途）、enclosure（enclosed 或 open）；围合处核四周以及入口。原图不清时保留待核。professional_review.room_label_names 列本户型需要在模型中显示的房名，按本图语言逐字填写。对合理开敞方向在房间行填写 open_sides，按 x 或 y 登记 context（perimeter 或 continuous_interior）、boundary、adjacent、source_evidence、use_check 和 clear_region_id。对应源图几何检查必须是同 room_id、同 axis 的 clear_region，净区多边形取在实际开敞处，经终稿复量无墙材。独审者核对净区位置、外缘栏杆或窗的身份及使用关系。卧室、卫生间按围合方向量测；门洞单独检查。审图者负责判断截线是否代表该房间、立面共面是否合理以及行走、操作空间是否可用。给出正常结论也须记录具体对象与证据；候选全部勾完仍需按原图查遗漏。

独立检查已有 DWG 时，先用 `native_readback.py` 取得含 capture.json 的目录。保留该目录中的 plan.dwg、readback.dxf。提供带 `rooms:[{"id":"房名"}]` 的 ledger，内含本案 `wall_layers` 与 `nonwall_fill_layers`。

```sh
python scripts/professional_review.py --capture 原生复开目录 --ledger ledger.json
python scripts/professional_review.py --capture 原生复开目录 --ledger ledger.json --assessment 专业独审.json
```

独立运行时，外层需有 `dwg_sha256`、`reviewer` 和 `issues`，每个问题填写 `id/kind/location/evidence/finding`。缺房、实量落点不在指定图元、零头无处理说明或候选无结论会返回“待补证”。有修正或用户决策事项时会分别列出。通过仅表示此版完成所列专业审查。
