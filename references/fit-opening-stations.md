# 从原图实墙端面量洞口两端

作者先在原图登记每樘窗、推拉门、侧光、平开门或净开口。每条记录有自己的 ID、种类及粗端点。使用本工具可在每个粗端附近重找墙芯尽端，并取得可合入 scene 的原图像素坐标。它适用于已校正透视的水平、垂直母墙。一个 ID 始终对应原来的一条登记。

## 输入和运行

使用原分辨率图片、作者的 `source-reading.json` 和本案测量设置。读图文件的 `source_sha256` 必须与图片一致。所有像素坐标均以按 EXIF 显示方向打开的原图左上角为原点，x 向右，y 向下。

- `source-reading.json` 的 `portals` 每项含 `id`、`kind`、`a`、`b`。种类可用 swing、sliding、window、sidelight、rail、open。原来的 a、b 顺序保留。清楚看见端部接邻框或自由端时，用 `end_support` 按 a、b 顺序填 wall、frame、free 或 unspecified。在阅读阶段已知图符模糊，可填 `symbol_legible:false`。
- 测量设置可以直接用本案墙芯取样文件。它的 `samples` 按深、浅墙分别登记 bearing 和 partition，每类包含原图内实心、无印字处的 `points_px`，可给 `radius_px` 和 `tolerance_rgb`。颜色只描述本图显示。可复用 `plan_box_px`、`exclude_boxes_px`、`nonwall_points_px`。遮住墙端的图签、装饰或阴影疑点可用排除框标在原图上。
- 比例可用本案的 `source_to_mm`，或用 `mm_per_px:[横向毫米每像素,纵向毫米每像素]`。两轴相同时也可给一个数。 `defaults.core_width_px` 给墙芯厚度的像素范围。 `station_search_px` 为从粗端沿墙能搜索的最大距离。`normal_search_px` 为从粗轴朝墙两侧搜索的最大距离。缺省范围按本案比例估计；低分辨率、加粗或特别薄的墙宜从原图量取。
- 可用 `portal_options` 按洞口 ID 单独设定上述范围。已有墙芯色段报告时可用 `axis_id` 指定同图母轴。没有站表时，可在本地搜索范围内用 `anchor_px` 指向一段清楚的母墙芯。若本洞宽度有明确印数，填写 `printed_width_mm`。若某个洞端明确受已标尺寸控制，填写 `dimension_controlled_ends:["a"]` 或相应 a、b 列表，该洞进入人工核对。

以下命令第一行独立运行。第二行使用同一原图的母轴报告。输出目录须为空。

```sh
python scripts/fit_opening_stations.py 原图.jpg source-reading.json 墙芯取样.json /临时检查/洞端
python scripts/fit_opening_stations.py 原图.jpg source-reading.json 墙芯取样.json /临时检查/带站表洞端 --guide-report /临时检查/母墙/guide-report.json
```

| 输出 | 用法 |
|---|---|
| `opening-stations.json` | 逐洞查 a、b 原粗点、拟合母轴、实墙端和邻框候选、三条切片、原图色阶及读差。图像、读图清单、设置和可选站表各有摘要。 |
| `opening-001.png` 等 | 上栏为原图，下栏标粗端（蓝）、有支持的墙端（绿）、待读候选（橙）和切片断点（白）。纵墙在卡片上转作横向阅读。JSON 中坐标均指向原图。 |
| `opening-updates.json` | 仅收录两端均有唯一支持、内部无另一段实墙、与邻洞无重叠、与已知尺寸无冲突的 `{id,a,b}`。核图后按 ID 更新 scene 中已有的洞口字段。既有宿主、墙段、支承和已标尺寸需要保持一致。 |

## 怎样读证据

1. 看母轴与端面。可选站表只参与母轴定位和提醒交叉结点。每个候选均重新查本图的像素。工具在墙厚方向找连成一片的实料，核对中心、全厚、材料、端外连续长度和端内剩余墙芯面积。尺寸刻线、窄饰面和柜边缺少相应墙芯厚度。
2. 看三条切片。切片平行母墙，分处墙芯中间和两侧。高可信端需至少两条切片显示相应颜色退出，另有墙芯面积与洞内空间支持。窗和推拉门还需看见至少两条同极性的独立框纹。单调的渐变边沿用原图亮度变化的中点估计端面，并在报告中保存原墙芯像素边界与渐变范围。原图被遮住或看见台阶、多解、横墙凸出、细框与墙同色时，查看所有候选。
3. 看读差。`uncertainty_half_band` 分沿墙和垂直于墙两方向给像素、毫米半带宽。沿墙读差考虑切片差异、反锯齿过渡和至少半像素的图像分辨率。垂直方向读差取实测断面中点相对母轴的偏移加半像素。它们只描述这次局部读数。未分出唯一端面时，这些值为 null。可见候选仍列原图断点、各自局部带宽及总包络。完全遮挡时无法从本图给出实际端位误差界限。
4. 看两端如何接墙。相邻玻璃或推拉门的小横框可有两侧框纹和一条明确横线。报告将其列为 `frame_only_choices`，记录整条笔画覆盖的像素区间；笔画中心不能直接代替实墙端面。不同构件、不同登记或相反端序始终分别核对。推拉门的开合方式、平开门的铰侧、窗扇数量仍按各自图符读取。
5. 将核准的 a、b 回填到同一母墙，并用这两个端面重新扣洞。若母墙由 `fit_wall_guides.py` 生成，按该墙的坐标方向回写 `span_px`，重新生成相应墙段、扣洞宿主及洞口。若采用其它 scene，按同一对端面同步核对实墙收头、墙垛、宿主范围和相连图符。保留印数、控制刻线和尺寸链；需要改已标尺寸时单独处理。坐标提案本身只写在新目录。

## 合成核验范围

在一张自绘原图上登记 12 条记录。清楚的相邻窗和推拉门由 6 px 的浅色墙垛隔开。另有带门槛的平开门和反向登记的纵窗。8 个粗端沿轴故意偏移 10.5–14.5 px。4 条记录均恢复到绘制时设置的半像素端面。人工查看了相邻推拉门、接框窗、台阶端的原图卡片。使用每像素横向 15 mm、纵向 20 mm 的不同尺度，8 个清晰端的读差分别为横向 ±7.5 mm、纵向 ±10 mm。

余下 8 条保留待读，包含共用横框的窗及侧光、墙肢台阶、遮挡、两个同样合理的端面、同位置登记为不同种类和与两侧轨道同色的短柱。带 2 px 横框的窗、侧光各自报告了该框的完整笔画范围。同图母墙站表接入后，明确印数冲突和被尺寸控制的端点均未进入更新清单。

对合成图另加轻微模糊并以 JPEG 保存，使用该图重新取色。12 条中有 2 条得到整洞提案，包括平开门和反向纵窗。其 4 个端面沿轴距绘制位置均不足 0.1 px。其余登记保留待读，包括浅色短垛与模糊轨线色阶接近的相邻窗和移门。这是已知真值的合成验证；未测真实户型的整户端位精度、墙性质或门窗清单完整率。
